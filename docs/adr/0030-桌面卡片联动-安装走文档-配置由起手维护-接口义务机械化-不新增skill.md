# 桌面卡片联动：安装走文档，配置由起手维护，接口义务机械化，仍不新增 skill

ADR-0029 定下桌面卡片本体并把它放进独立仓库，首版今天通过 Windows 人手验收，本会话另在真实宿主上复核过一遍：三案齐、排序对、拷入新案下一轮自动出现。剩下的是两仓之间的联动，#90 与 #91 要答的就是这个：律师从 skill 这边装完，不知道有那个东西；卡片的根目录要他自己填；`格式版本` 升版要通知卡片这条义务只写在 ADR-0029 的正文里，靠人记。

本会话核实过的事实：律师那条安装路（skills.sh）只把 `skills/<bucket>/<name>/` 一个目录拷到本机，Claude Code 插件路线装的是只读整包，**两条路都没有安装期钩子**。所以「只引用 skill 仓库就自动把卡片装上」在现有分发机制里不存在，不是没配好。能落到律师机上的只有两样：文档，和 skill 包里的东西。

我们决定：

- **安装走文档，命令的正本留在卡片那个仓库。** 本仓库根 `README.md` 加一节「桌面卡片（可选）」，说它是什么、读什么、装过之后起手会替他维护根目录，安装命令只给一个链接。`.agents/install-block.md` 收下这个块并记一条规矩：卡片的安装命令不抄进本仓库。两个仓库各写一份同一条命令，迟早有一份先改、另一份不知道；而装卡片本来就没法自动化，律师还得先装宿主。
- **配置自动化落在起手的 CLI 收尾。** `setup-case` 把新工作区的**上级目录**加进 `~/.loo0ng/卡片设置.json` 的 `根目录` 列表。判据是死的：那份设置不在就整步不做、不创建、回显里也不提（那台机器没有卡片）；已经在列表里就一个字不动；加，不删不改，顺序不重排；读不出、形状不对、写不进都只回一句，起手照样算完成；`--no-card` 整步关掉。
- **不问律师。** 起手清单是那条路上唯一的确认点，这一步不在它前面加问句，也不在它后面加第二个。它只往一份本机个人文件里加一行，加错了删掉就是，够不上一个确认点。
- **写的是包外的家。** 改的是 `~/.loo0ng/` 下的个人文件，不是本仓库，也不是案件工作区；ADR-0023 已为个人预设图开过这个口，硬边界 2 的射程不变。「家」那一层仍由 `LOO0NG_HOME` 换，脚本层单测据此碰不到律师真的那一份。
- **仍不新增 skill，一个登记点不动。** ADR-0029 的那条继续成立：卡片与 agent 之间没有调用关系，引擎写、卡片读。这一轮没有新 skill、没有新命令、路由两张表不动、双旗不动、不 relink。
- **接口义务机械化。** `scripts/check-release.sh` 多一条：图引擎的 `FORMAT_VERSION` 与上一个 tag 不同就提醒「通知桌面卡片那个仓库」。提醒级，不挡发版；它把 ADR-0029 记下的那条人力义务变成发版前必然被念一遍的东西。
- **ADR-0029 的「不动 loo0ng-skills」在这一处放开，射程只限这一处。** 那条写的是卡片仓库不得反向要求本仓库改接口（不加字段、不升版、不新增 skill）。本 ADR 动的不是接口，是起手对一份本机个人文件的维护；接口一个字没改，`GRAPH-FORMAT.md` 一个字没动，仍不许出现卡片仓库的名字。
- **卡片那边今天开的两票属于下一版。** 一层扫描顶不住实际摆法（开发机上见到过工作区落在根目录下第三层的摆法，那样的案件卡片永远发现不了），以及旧格式的读不出原因对律师不可行动。两票都在卡片仓库，本轮不做：它们要么要正面裁 ADR-0007 有意不答的那件事，要么属于呈现那一轮。

## 考虑过的方案

- **新增一件「装卡片」skill**：能覆盖律师那条路，但要正面推翻 ADR-0029 的「不新增 skill」，并把结构不变量 1、2、3 的登记点全过一遍，换来的是省去一次照着 README 粘命令。等卡片的呈现定形、真要交到律师手上那一轮再判。
- **做成一条 slash command**：走 skills.sh 的律师机只拿得到 skill 目录，命令根本装不过去。载体选错，覆盖不到唯一要覆盖的那台机器。
- **起手时把每个案件登记进一份清单**：ADR-0029 已否，理由不变（多一份要维护的状态）。扫根目录加一次性配置已经够。
- **把安装命令抄进本仓库 README**：两份正本迟早走样，而且卡片的宿主要求与它的版本绑着，抄过来的那份不会跟着走。
- **让卡片自己猜一个默认根目录**：等于把 ADR-0007 有意不回答的「工作区之上怎么摆」偷偷回答了。
- **起手清单里多问一句「要不要加进卡片」**：破坏「唯一确认点」这条形状，换来的是一次可以直接撤销的写入的知情权。回显里说一句已经够。
- **没有设置文件就替他建一份**：那台机器没有卡片，建出来的是一份没人读的文件，以及一句他看不懂的回显。

## 后果

- `skills/engineering/setup-case/`：`SKILL.md` 多三处（一条命令那一节的说明、收尾五行之后照抄卡片那一行、与邻居的边界多一条），`scripts/setup.py` 多一个 `--no-card` 与一段维护逻辑，脚本层单测多八条。
- `README.md` 多一节；`.agents/install-block.md` 多一个块、一行消费方、一条规矩。
- `scripts/check-release.sh` 多一段格式版本比对（提醒级）。
- `CONTEXT.md`：「桌面卡片」词条补一句根目录设置的归属，Relationships 多一条**起手**与**桌面卡片**之间的边。
- 卡片仓库这一轮零改动。它的两票与呈现设计在下一版处理。
