# 安装顺序按律师排，skills.sh 在前，自建插件市场保留

#56 要裁定律师与开发者的安装路线及 README 的先后。律师自行安装先走 skills.sh，README 将它列在首位；开发者沿用当前 Claude Code 插件、Codex 需要时走 skills.sh 的分工。每个 agent 只装一条路线，junction 仍是维护者开发工具。开发者在本会话中明确回复「采纳」，批准本文与 README 的安装路线方案，状态据此改为 accepted；编号按 #56 预留的 0026 使用。

## 依据与取舍

[上游安装文案](https://github.com/mattpocock/skills/blob/959a8e9/.agents/install-block.md)与[上游 README](https://github.com/mattpocock/skills/blob/959a8e9/README.md)在这个固定提交中，先列 Claude Code 官方市场，再列 skills.sh。它不向用户文档化自建市场，是因为已有官方市场取代它。本仓尚无该官方入口，直接删去自建市场说明会让需要插件的用户失去现有安装入口，因此保留在第二位，明确其用途与验证范围，不照抄上游的隐藏策略，也不承诺官方市场的自动更新行为。

[律师 Mac 现场结论](../实测/mac-20260909/结论.md)记载：skills.sh 在私有仓库下三次失败，仓库转 public 后安装成功，现场四段走通。成功仅有口述记录，没有本轮退出码或报错原文；该记录没有证明公开仓库下插件安装成功或失败。选择 skills.sh 为律师首选依据的是已有现场成功，而非两条路线的优劣对照试验。公开安装源的约束继续保留。

[开发约定](../agents/skills.md)记录开发者当前 Claude Code 使用插件，Codex 要用时走 skills.sh；这不必与律师首选相同。README 原来把插件列在第一位，反映的是平台与开发者的用法，没有按律师现场已走通的路线排序。此次改为律师优先，同时保留开发者分工，并把去重约束明确到每个 agent，避免被误读为两种 agent 不能各选一条路。
