# 维护者资产有意保留，历史资料不作现行规则

## 判据与清点

## knowledge 的边界

六份文件各有用途：`规范/案件目录规范.md` 与 `规范/快照规范.md` 说明旧布局和旧状态模型；`流程模型/破产.md` 保存从指引、手册切分内容的结果；`文书卡/债权审查确认表.md` 保留单件文书的内容素材；`模板/登记表.md` 保留模板来源、哈希与旧挂载关系；`通用裁定台账.md` 保留去案件化裁定及事故形态。全部保留原位，不为适配当前术语批量重写旧记录。

当前 `knowledge/模板/` 只有登记表，19 件官方 DOCX 已在 `skills/engineering/domain/assets/预设图/破产/模板/`。旧登记关系不构成第二份出厂预设图，也不是加载模板的入口。办案运行读取随包资源，不回头读取这六份资料。

词汇以 `CONTEXT.md` 为准，skill 行为以正文为准。保留旧资料沿用的是 ADR-0001 的素材定位，没有把其中「只增不改」「全部下游遵守」等旧机制重新提升为产品约束。通用裁定的开发侧誊入仍受根 AGENTS.md 的硬边界、隐私守门和第二双眼要求约束；本裁定不新增办案会话写仓库的渠道。

## 实测二进制的取舍

两份样例共 38,900 字节。逐件 SHA-256 比对，`样例A-单页.docx` 与当前出厂模板 `1-2.关于管理人印章备案的报告.docx` 完全相同，`样例B-多页带页脚.docx` 与 `3-1.关于提请法院裁定确认无异议债权的报告.docx` 完全相同。它们是官方空白模板的测试输入副本，未发现相对原件的填案改动；哈希一致不等同于另做过一次隐私审计。

仍保留这两份固定样例：旧探针通过样例名读取它们，特别是 B 的页脚与版式是当时排障的输入。改成每次从最新出厂模板取件，会让历史试验输入随模板升级而变；只删二进制则留下不能完整复核的探针包。约 38 KiB 的固定副本成本可接受，它们不参与模板分发与案件起手。

保留的是实验输入和已去案件化的结论，不是授权收录案件材料、整机原始回传、生成的 ZIP 或输出目录。`docs/实测/打包.py` 的存在也不恢复已经退场的离线发布机制；未来再用旧探针或打包流程，应按当次目的核对适用性。2026-09-09 的结论已明确只有口述、没有本轮退出码和报错原文，本 ADR 不提高其证据等级。

## 没选的方案与后果

- **为了形似上游全部删掉**：会丢失当前验证、交付依赖及历史证据，上游目录形状不足以抵消这些损失。
- **搬到另一个仓库或私人资料目录**：需额外维护版本对应、访问权限与跨仓链接，目前这些对象合计不足 1 MiB，没有足以承担这些成本的收益。
- **只搬走历史部分或只删重复 DOCX**：会打断已有引用或拆散探针与固定输入；分类可通过本 ADR 表达，无需先改物理路径。

本裁定有意保留这些上游没有的维护者资产，不表示其中每个历史判断继续有效，也不表示任何新增资料都应入库。以后出现具体冗余或更合适的归宿，再按对象提出搬删方案并核对引用。本票不增测试、不改运行行为、不写 changeset、不重跑 relink；验收按 #58 评论执行文本、skill、接线及插件校验。
