# 现场交付清单：在律师那台 mac 上装好 3.0 并初步跑通

**执行的人是开发者本人，在律师那台机器前现场做。** 不是交给律师自助的向导，也不是 agent 能替的：那台机器不在这里。律师只做三件事：点授权、念他在客户端里看见的东西、在拍板那一句里说话。

**这份清单没法预先跑通一遍。** 开发者手边没有 mac，凡是拿不准的步骤在正文里标成 `⚠️`，并在末尾的「拿不准的七处」里汇总。**现场照实记，别在这里猜一个答案写进去，也别就地想办法绕。**

## 怎么用

- **断网可用。** 要打的每一条命令、每一条预期回显都写在这份文件里，现场不用去翻 issue、翻仓库、翻网页。凡是引到票号的地方，结论已经抄在正文里，票号只作溯源。
- **每做完一步，把结果记进 `记录表.md` 的同号那一行**：命令、退出码、报错原文、当场怎么处置的。填不出来的写「未跑到（卡在 X.y：…）」，不要留空、也不要编。
- **失败本身就是结果。** 三条路的第 1 条不成就降第 2 条，不要去找 GitHub 令牌、不要让律师去登录、不要装什么把缺的东西补上。
- **不改任何 skill 正文**（#83 边界）。现场发现该改的，逐条记进记录表末尾的「带回去的票」，回来另开票。
- **案件内容不进记录表、不进 issue、不进 commit message**（硬边界 1）。段 3 与段 4 用的是真案子，所以记录表里只记「第几步、退出码、卡在哪」，节点标题、当事人、文件名、路径一概不抄；要举例就写成 `<节点标题>`。

## 段 1　装

律师用的是 Codex 客户端。装法三条路，**从 A 往下降，成一条就停**，把走通的那条记进记录表 I6。

### 1.1　路 A（首选，要网）

```bash
npx skills@latest add f4de01/lawyer-workbench-v3 -a codex
```

安装器会让你挑 skill 与目标 agent：**七件全选**，agent 选 codex。**安装源必须是公开仓库**：2026-09-09 那趟私有仓库没走通，最后是把本仓库转成 public 才装成的（`docs/实测/mac-20260909/结论.md`），本仓库至今是 public，照上面这条直接装。

⚠️ **这一步在仓库还是私有的时候失败过三次**：一次报 `Error in the HTTP2 framing layer`（网络），一次报 `Authentication failed for https://github.com/...`（凭据），2026-09-09 那次没留回显。失败就照记退出码与报错原文，降到路 B，**不要去弄令牌、不要让律师登录**。

⚠️ 还有一个坑：上一轮的判据是「`~/.agents/skills/loo0ng-doit` 这个目录在不在」，而上上轮拷进去的还在，于是**明明失败却判成了成功，用的还是旧文件**。这一轮的判据改成看时间戳：

```bash
ls -la ~/.agents/skills/ | head -20
stat -f '%Sm %N' ~/.agents/skills/*/SKILL.md
```

装之前先看一眼这两条的输出，装之后再看一眼，**时间戳没动就是没装上**，不管安装器说了什么。

### 1.2　路 B（本机 `gh` 已登录时）

```bash
command -v gh && gh auth status
gh repo clone f4de01/lawyer-workbench-v3 ~/交付包/repo
npx skills@latest add ~/交付包/repo -a codex
```

⚠️ 这台机器上有没有 `gh`、登没登录，都不知道。没有就直接降路 C。

### 1.3　路 C（离线兜底，一定成）

把 U 盘上的 `skills-兜底/` 七件直接拷进 `~/.agents/skills/`：

```bash

```

客户端与 CLI 读的是同一个目录，**直接拷对客户端一样有效**（上一轮实测坐实过）。

### 1.4　装完必做的三查

```bash
# 一、七件都在（期望列出七行）
ls -1 ~/.agents/skills | grep -E '^(ask-loo0ng|loo0ng-)'

# 二、name 行逐字，且行尾没有 CR（mac 的 cat 没有 -A，用 -v -e）
grep -h '^name:' ~/.agents/skills/*/SKILL.md | cat -v -e

# 三、SKILL.md 一个都不许带 BOM
for f in ~/.agents/skills/*/SKILL.md; do printf '%s ' "$f"; head -c 3 "$f" | od -An -tx1; done
```

- 第二条期望七行，每行形如 `name: loo0ng-doit$`；出现 `^M$` 就是带了 CR，回到 1.3 重拷并跑一遍 `perl -pi -e 's/\r$//'`。
- 第三条期望没有一行是 `ef bb bf`。

七个名字逐字应当是：`ask-loo0ng`、`loo0ng-doit`、`loo0ng-domain`、`loo0ng-filing`、`loo0ng-graph`、`loo0ng-setup-case`、`loo0ng-to-docx`。**一个字符都不要改、不要补全、不要顺手规范化**，磁盘上是什么样就抄什么样。

| E14 | `ls -la "$S"`；`python3 -m pip list 2>/dev/null \| grep -i docx`；`ls ~/Library/Python/3.9/lib/python/site-packages 2>/dev/null` | 三处都要看：skill 目录里没有多出 `libs/`、`site-packages/` 之类；`pip list` 里没有被新装东西；**`~/Library/Python/3.9/…/site-packages` 是 `pip install --user` 在系统 python 上的真实落点**，段 2 跑完它里面不该多出 `docx`（E3 那个 1.2.0 本来就在，记清楚它原来落在哪、是不是这里） |
| E15 | **故意制造一次版本不符**（#79 第 4 项）：`python3 -m pip install --no-index --find-links /Volumes/<U盘>/交付包/wheels-alt --target "$T/alt" python-docx==1.1.2 --no-deps`，再 `PYTHONPATH="$T/alt" python3 "$S/scripts/md2docx.py" "$T/印章备案.md" --template "$TPL" --out "$T/out-alt.docx"` | **退出码仍是 0**（版本对不上照跑，ADR-0018），第二行应当是 `…；python-docx 1.1.2（依赖清单钉的是 1.2.0，这不是钉住的那个版本）`。开发机上 2026-09-08 实跑过，就是这一行。逐字抄进记录表 |

E12 在开发机上（2026-09-08 实跑）的回显是这个形状，可作对照：

```
版式门禁：通过
不通过项：无
披露项：
- 空单元格：第 1 张表 第 2 行第 2 格
- 无渲染结果：页数、空白页、最大行高按版面推算给出区间（按 --no-render 跳过）
- 页数：推算 1 页
```

那一行**括号永远在**，括号里是这次没有渲染结果的原因（`gate.py` 恒写 `（%s）`）。开发机上那次是显式加了 `--no-render`，所以是「按 --no-render 跳过」；**这台机器上不必加 `--no-render`，那条披露项自己会出现，括号里应当是「找不到 powershell.exe」**（门禁找不到渲染通道时的原话）。逐字抄进记录表，与这句对不上就照实记。

### 这一段结论怎么写

一句话，三选一，写进记录表的「E-结论」：

- **落得地（组一成立）**：这台机器现装的 `python3` 直接跑得动转换器与门禁，自备环境不必触发。
- **落得地（组二成立）**：现装的不够，但按 ADR-0018 的四条约束自备一次走得通，走的是 `uv` 还是离线 wheel 那条。
- **落不了地**：两组都不成，卡在哪一条、报什么。**这时候要指出该改 ADR 还是该改实现，但不在现场改。**

收尾：`rm -rf "$T"`。

## 段 3　起手一个案子

在一个**空目录**里走完六格、起手图、归档、雏形、起手清单、拍板。这一轮是**真使用，不是 eval**，不承担任何门槛。

### 3.1　挑目录

跟律师一起挑一个空目录作案件工作区，**在这台机器上、不在任何仓库里**。⚠️ 别放 iCloud 同步的位置（「文稿」「桌面」多半是同步的），中途同步会把半截产物搬走。路径**不抄进记录表**（硬边界 1），记录表 S1 只写「已选定；不在仓库内：是 / 否；不在 iCloud 同步目录内：是 / 否」。

### 3.2　把这个目录在 Codex 客户端里打开成项目

⚠️ **客户端有时会把任务放进它自己的临时副本或 git worktree**，那个目录和律师看到的文件夹不是同一个。开工第一句先让它自报位置：

```
先跑一句 pwd && ls -a && git rev-parse --show-toplevel 2>/dev/null，把输出念给我，别做别的。
```

`pwd` 不是那个空目录就停下来，换个开法（把文件夹拖进窗口、或用项目选择器重开），**不要在副本目录里起手**。记录表 S2 记它实际在哪（写成相对形状，不抄绝对路径）。

⚠️ 它要是问「这个文件夹不是 Git 仓库、要不要初始化」：**不要**。案件工作区不是仓库。

### 3.3　律师打起手那一句

由**律师本人**在客户端里打（这是他日后每天要做的动作，得让他打一次）：

```
$loo0ng-setup-case 这个案子归我了，在这个目录里起手，领域是破产。收件箱里的东西你一并归了。
```

⚠️ 先打 `$loo` 让补全筛出来再选，别只打 `$`（列表太长，七件不在首屏）。

后面那句自由文本是律师自己的话，**不用照抄**；要点只有两个：说清领域（破产），以及要不要在这句里就把起手图三选一说了。说了它就不问，没说它会只问这一件（下一步）。

⚠️ **`$名` 显式提及能不能触发隐式关闭的 skill，在 Codex 客户端上没测过。** #20 在 Codex **TUI** 上测成了（`allow_implicit_invocation: false` 的 skill 用 `$名` 照样触发），客户端是另一个壳。不触发就记原样反应，然后退到 3.3'。

3.3'（现场兜底）：把 `~/.agents/skills/loo0ng-setup-case/SKILL.md` 直接拖进对话或让它读一遍，再说「按这份起手」。**这是现场兜底，不是设计**，照实记成「显式提及未触发，用了兜底」，并开一张票带回去。

### 3.4　起手图三选一

模型会只问这一件，给三个选项：整份领域图（最常见）／空图／开发者交付的定制图。**这是人的决定，让律师选。**

领域目录路径它自己取，**只打一条命令**：`init --domain-name 破产`（#97）。活图路径由那条命令自己子进程调 `~/.agents/skills/loo0ng-domain/scripts/sketch.py home --name 破产` 取回，不需要模型先跑一遍、也不需要谁把路径抄给它。第一次起手这个领域时，它把包内的出厂种子（`~/.agents/skills/loo0ng-domain/assets/破产`，22 件约 540 KB）整份拷进 `~/.loo0ng/领域/破产/`，之后只认后面这一份：**律师往后累计在领域目录上的东西住在 skill 包之外，再装一次、升一次级都碰不到它**（ADR-0019）。拷贝零点几秒，不该看见等待。⚠️ 上面那个 `~/.agents/skills/` 是路 A / 路 C 装出来的形状；路 B 或客户端插件市场装出来位置不同，两件 skill 仍是兄弟目录，`setup.py` 按自身位置推得出兄弟的 `sketch.py`，**种子在哪它也自己算得出**（同一条推法），不用另外告诉它。

### 3.5　核六格与两份指针

```bash
find <案件工作区> -maxdepth 2 -not -path '*/.*' | sort
```

单层 `ls` 看不到 `材料/律师陈述/`、`模板/官方/`、`模板/生成/` 这三格，所以用 `-maxdepth 2`。期望：`图.json`、`图视图.md`、`图视图.json`、`收件箱/`、`材料/`、`材料/律师陈述/`、`指南/`、`模板/`、`模板/官方/`、`模板/生成/`、`AGENTS.md`、`CLAUDE.md`。`文书/` 出件时才建，这时候没有是对的。

`模板/官方/` 里应当有起手图挂到的那几件官方模板原件。⚠️ 领域目录里一共 19 件模板，整份领域图挂到的那些要逐件拷，慢一点是正常的，别以为它卡住了。

`AGENTS.md` 四项都在：领域名与领域目录绝对路径、图与视图文件名、入口名、「本工作区对 skill 仓库只读」。`CLAUDE.md` 只有一行 `@AGENTS.md`。

### 3.6　归档与雏形

`收件箱/` 里有律师这个案子已有的文件就让它归档（判去向归模型，律师不逐件参与）；`指南/` 归档后非空就会跑一次雏形 `check`（**只 check 不 apply，图一字不动**）。

⚠️ **整读指南是这一路上最慢的一步**，指南长的话可能要好几分钟，也可能撞上客户端的回合或时长上限。撞上了记原文，别催它。

### 3.7　起手清单与拍板

它回显一张表（要在图上建的 / 建议登记为已生成的既有成品 / 待定），**这是起手唯一的确认点**。律师一句话拍板整张（「都按建议登记」「照这个建」「第 3 条不要」），**说了才写图**。

⚠️ 要是它**先写图再问**，当场停下来，记进记录表 S7 并记一张「带回去的票」。这是 ADR-0008 的硬规矩被破了。

### 3.8　核一遍

```bash
python3 -c "import json,sys

print('领域', g['领域'], '模块', len(g['模块']), '节点', sum(len(m['节点']) for m in g['模块']))" <案件工作区>/图.json
```

（`图.json` 顶层只有 `格式版本`、`领域`、`模块` 三个键，模块内嵌 `节点`、节点内嵌 `条目`。）

记录表 S8 只记模块数与节点数、`图视图.md` 的形状对不对，**不抄标题、不抄内容**。

## 段 4　初步跑通一个节点

至少一个节点走完出一版加拍板，**要看的是审查报告与门禁三档在没有渲染后端时长什么样**。

### 4.1　出一版

还是律师本人打：

```
$loo0ng-doit 出一版 <他要办的那个节点>。材料里没有的先照出，缺什么列进审查报告告诉我。
```

后半句同样是律师自己的话，不用照抄。**它写在这里是因为「生成不问缺事实」是设计**：缺项进审查报告的「待律师裁定」，模型不会停下来问；律师答一句，那句先落成陈述再重出。现场看它是不是真这么走。

⚠️ 挑节点时优先挑**有官方模板、材料齐**的那种。第一次别挑长文书：页数一多，门禁的页数区间横跨 30 页阈值，结论会是「需人眼」；那也是要看的形态之一，但不适合第一次。

### 4.2　这一段要看的四样（**最要紧的**）

一版出完，把下面四样**逐字抄进记录表**（只抄这四样的形状，不抄案件内容）：

1. **转换器回显第二行**：`出件环境：解释器 …（python 3.9.6）；python-docx 1.2.0（与依赖清单钉的一致）`。它有没有被模型抄进审查报告的「生成依据」段？
2. **门禁结论那一行**：`版式门禁：通过` / `需人眼` / `不通过`，与退出码（0 / 3 / 1）。退出码 2 是门禁跑不动（文书或模板打不开、推算层抛异常、用法错误、落盘被拒），照旧记原文。
3. **披露项里那条无渲染的**：这台机器上必然出现，形如「无渲染结果：页数、空白页、最大行高按版面推算给出区间」。**有渲染结果时才有的两条披露项（请求字体不在嵌入字体里、有字没渲出来）应当整条消失、不报「无」**，核一下是不是这样。
4. **结论是需人眼时**：审查报告开头**第一段**是门禁生成的须目验清单（每行一项，带项名、坐标、推算区间、最坏越界幅度，末尾一句「确认前请在 WPS 或 Word 里打开看这几处」），**它由门禁生成，不许模型改一个字**。核它在不在、在不在第一段（在「生成依据」之前）。

### 4.3　落盘三件与图上那条

```bash
ls -la <案件工作区>/文书/<节点标题>/
```

期望三件同目录：`<标题>-v{n}.docx`、同名 `.md`、`<标题>-v{n}-审查报告.md`（`<标题>` 就是节点标题，`{n}` 是这个节点算上这一版的生成条目数，第一版即 1）。**通过与需人眼都落盘**，位置相同、文件名不加任何装饰；不通过什么都不落，那时 `文书/` 下应当没有这个目录。

审查报告五段固定、顺序固定：**生成依据、存疑点、待律师裁定、版式门禁、时限**。结论为需人眼时，标题之后、「生成依据」之前另插一段须目验清单，那是唯一会插在五段之前的东西。

图上应当多一条生成条目，三条路径都指着真文件。`图.json` 顶层只有三个键（`格式版本`、`领域`、`模块`），模块内嵌 `节点`、节点内嵌 `条目`，所以只数条目、不抄内容：

```bash
python3 -c "import json,sys
g=json.load(open(sys.argv[1],encoding='utf-8'))
n=[x for m in g['模块'] for x in m['节点']]
print('模块', len(g['模块']), '节点', len(n), '条目', sum(len(x['条目']) for x in n))" <案件工作区>/图.json
```

要看那条条目本身的形状（不抄内容）就 `python3 -m json.tool <案件工作区>/图.json | tail -40`。

### 4.4　拍板

律师在**同一个对话**里说确认（「确认 X」）。图上再多一条确认条目，原样存着他那句话。下一个节点开新对话。

### 4.5　整段走不通时的兜底

「出一版」整个走不通（模型不触发、转换器起不来、客户端撞上限），**退到只跑门禁**：门禁本体零第三方依赖，对任意 DOCX 都跑得动，律师手上现成的文书就能检一份。

```bash
python3 ~/.agents/skills/loo0ng-to-docx/scripts/gate.py <律师现成的某份.docx>
```

这不是一次生成（不落 `文书/`、不写审查报告、不动图），但它能证明门禁在这台机器上跑得动，也能看到「无渲染」形态。记录表 D5 记退出码与结论。
