# 现场记录表

配 `现场清单.md` 用。**现场逐行填，回来再整理。**

- 每行填：命令实际打的样子（有改动就写改动后的）、退出码、报错或回显原文、当场怎么处置的。
- **填不出来的写「未跑到（卡在 X.y：…）」，不要留空、也不要编。**
- **只记事实，不下结论。** 「这条路可行」「建议改用某某」都不写在这里，判断回来再做。
- 编号跟 `现场清单.md` 对齐。带字母或撇号的（`I7a`、`E9'`、`S5b`、`D4b`）是**同一步的分项**，不是清单里另有一步；清单里说「记进同号那一行」时，找它的主号即可。
- **编号不回收**：版式门禁退场之后，旧表里的 `E5`、`E6`、`E12`、`E12b`、`D3`、`D3b`、`D3c`、`D4a` 整条没有了，号也不给别的步骤用。这一版新加的是 `I7d`、`E11b`、`E11c`、`E16`、`E17`、`S4b`、`S5c`、`D1b`、`D2c`、`D2d`、`D4f`、`U9`。跟旧记录表对读时按号对，对不上的就是退场或新加的那几条。
- **案件内容一个字都不进这份表**（硬边界 1）：不写当事人、节点标题、文件名、案件路径。要举例写成 `<节点标题>`、`<案件工作区>`。
