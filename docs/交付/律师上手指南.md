# 上手指南：从装好到第一个节点办完

对着这份从头走一遍，你会得到：一套装在 Codex 里的办案工作台、一张常驻桌面的案件卡片（可选）、一个起好手的案件工作区，以及第一份出好的文书。

**全程你只在 Codex 里说话。** 装东西、建目录、改设置都交给它去做，你不用打开终端、不用记命令。下面每一步给的都是「你对 Codex 说的一句话」，照抄进去就行，它怎么做是它的事。

**碰到跟这里写的不一样的，停下来记一笔，别自己修、别自己装东西补**，见最后一节。

对应版本：skills `0.6.2`。抄件会漂，正文里的事实以仓库里的原件为准：七件 skill 的名字见 `README.md`，起手的一问二选见 `skills/engineering/setup-case/SKILL.md`，办节点的打法见 `skills/engineering/doit/SKILL.md`，卡片的装法见卡片仓库 `loo0ng-widget` 的 `README.md`。

---

## 第 1 步　装工作台（七件 skill）

打开 Codex，说这一句：

> 为我安装 https://github.com/f4de01/loo0ng-skills 的 skill，七件全装，装给我自己用。装之前先看看这台机器上 python3 是不是 3.9 以上，不是就先告诉我、别硬装。

它装完之后，**验一下**：新开一个 Codex 会话，打

```
$setup-case
```

它应当认出这个入口并开口说话（多半是说当前目录还不是案件工作区，这是对的）。打出 `$` 之后客户端能补全出 `setup-case` 就更明确。

**认不出来就停在这里记一笔**，别让它换别的办法硬装。

以后要升级，对它说一句「把 loo0ng-skills 更新到最新」。

> 它要是不知道该怎么装，把这一条给它：`npx skills@latest add f4de01/loo0ng-skills -a codex`。这是这套工作台在 mac 上唯一走通过的装法。

---

## 第 2 步　装桌面卡片（可选，建议装）

卡片是一张常驻桌面的小窗口，把你在办的几个案子并排列出来：每案的当前模块、进度、下一个要办的节点。它**只读不写**，不装也不影响上面那七件。

> ⚠️ **这一步在 mac 上还没有人从头走通过。** 装不上、装上了起不来、或者卡片里一个案子都不出现，都属于已知可能：记一笔交给开发者，别让它绕路自己想办法。

对 Codex 说：

> 装一下桌面卡片 https://github.com/f4de01/loo0ng-widget ，照它 README 里 mac 那条命令装。它要的宿主 Zebar 也一起装上。装完帮我建 `~/.loo0ng/卡片设置.json`，根目录填 `/Users/我的用户名/案件`（换成你放案子的那个文件夹）。

那个「根目录」就是你所有案子的上级文件夹。卡片扫它**下面一层**：这一层里的每个文件夹，只要是案件工作区，就是卡片上的一行。可以填多个。

装完之后**打开卡片这一步得你自己点**（Codex 点不了菜单）：mac 菜单栏里找到 Zebar 的图标，进 `Widget packs` → `loo0ng` → `案件卡片` → `Run '默认'`。列表里没有就让 Codex 把 Zebar 重启一次。卡片会出现在程序坞里，最小化之后从那里还原。

这份设置你以后不用再碰：**每起手一个新案子，工作台会自动把它的上级目录加进去**，卡片下一轮扫描（5 秒）就看得见。

## 第 3 步　起手第一个案子

1. **建案件文件夹**，对 Codex 说：

   > 在 `/Users/我的用户名/案件` 下面建一个文件夹叫 `<这个案子的名字>`（换成你的路径和案名）。

2. **让 Codex 到那个文件夹里工作**：客户端里把工作目录选成它，终端里的 Codex 就是在那个文件夹里开会话。这一步很重要，**起手认的就是「当前目录」**。

3. **打起手**：

   ```
   $setup-case
   ```

4. **它只问你一件事**：空图起手，还是用哪一份预设图。出厂带的那份叫 **破产**：12 个模块、72 个节点，外加 19 件空白模板。第一个案子建议就用它。回一句「用破产那份」即可；你在第一句里就说了（`$setup-case 用破产那份`），它不会再问。

5. **它会落下这些**，不用你做什么：

   ```
   <案件文件夹>/
   ├── 图.json  图视图.md  图视图.json   ← 这一案的台账与两份视图
   ├── 待归档/       ← 你原先丢在这个文件夹里的东西，全挪到了这里
   ├── 材料/
   ├── 参考/模板/  参考/指南/
   └── 文书/        ← 出件时才长出来
   ```

6. **最后它给你一张起手清单**：待归档里每一件它建议归到哪一格，等你一句话拍板。你可以说「都按建议来」，也可以说「第 3 条不要」「4 归材料」。**说了它才动**。没有文件要归就没有这一张。

7. 装了卡片的话，这时回显里会多一行「桌面卡片的根目录已加上 …」。没装卡片就没有这一行，正常。

起手一案只做一次。做完这一步，这个案子就成型了。

---

## 第 4 步　办第一个节点

**一个对话办一个节点。** 起手那个对话到此为止，下面开一个新的（仍然在这个案件文件夹里）。

1. **出一版**：

   ```
   $doit 出一版 管理人承诺书及团队人员
   ```

   节点标题照图里的写；记不住就先问路（见下一节）。它会照空白模板出一版，落在 `文书/<模块>/<节点>/` 下面，同目录还有一份审查报告。

2. **黄色的地方是留给你的**。收尾时它会说这一版黄色标在哪几处。用 WPS 打开就行，不需要 Word。两条路，随你：

   - **在 WPS 里直接填**：把黄色处写上，去不去掉黄色都行。
   - **在对话里告诉它**：把事实说给它，同一个对话里再打一次 `$doit 出一版 <节点>`，它重出一版。**你自己填过的字它一个不碰**，只动仍然黄着的地方和你点名要改的地方。

3. **拍板**：

   ```
   确认 管理人承诺书及团队人员
   ```

   这一句**在哪个对话说都行**：你在 WPS 里填完，隔几天新开一个对话说这一句，照样算数。黄色清光不等于办完，**办没办完只由你这一句话说了算**。

4. **下一个**：拍板之后它那一行直接给你下一句该打的命令（`$doit 出一版 <下一个节点>`），复制、开新对话、贴进去。

## 常用的几句

| 你想干什么 | 打什么 / 说什么 |
| --- | --- |
| 这案走到哪了、下一步做什么 | `$ask-loo0ng`（后面跟一句自由的话也行） |
| 这份我自己写好了 | `$doit <节点> 我自己写好了` |
| 这个节点本案不办 | `$doit <节点> 不适用`；整块不办：`$doit 模块 <模块> 不适用` |
| 法院退回要改一版 | 对已确认的节点再 `$doit 出一版 <节点>`，点名要改哪几处 |
| 图里没有我要做的事 | 还是 `$doit 出一版 <你说的标题>`，它把节点建进图再出件 |
| 把一堆文件整理进本案 | 在对话里说一句「把那个目录整理进来」「归一下待归档」 |
| 加个节点、改标题、挪模块 | 在对话里说一句「加一个节点 X」「把 X 挪到 Y 模块下」 |
| 把这一案的图留给下一案用 | 在对话里说一句「把这个案子的图存成预设图叫 <名>」 |

打法只有一个形状：**`$` 加裸名**，不带前缀（是 `$doit`，不是 `$<插件名>:doit`）。后面跟的话怎么说都行。

## 出问题了怎么办

**别自己修、别让它绕路自己想办法、别改工作台的文件。** 记三样交给开发者就够了：

1. 你说的那一句（原样）；
2. 它回的那段话（原样，报错整段都要）；
3. 当时在哪个文件夹、哪一步。

案件内容不用抄给任何人：把节点标题写成「某某节点」就行。

## 已知的几处毛病（都在修的名单上）

- 卡片**只认当前的图格式**。更早以前起手、之后没被工作台改过的案子，卡片会把它列进「读不出」，那种图没有升级路径，重新起手就好。
- 卡片只扫根目录**下面一层**。案子如果套在更深的层里（比如「根 / 分组 / 案件 / 版本」），卡片看不见它，界面上也不会提示。
- 卡片默认大小下，底部那个「扫一次」按钮和状态行要往下滚才看得见；它本来就每 5 秒自己刷新，不点也行。
- 装卡片之前就已经起手的案子，不会自动进卡片，得手工把它们的上级目录补进 `~/.loo0ng/卡片设置.json`（对 Codex 说一句让它加也行）。
