# 上手指南：从装好到第一个节点办完

对着这份从头走一遍，你会得到：一套装在 Codex 里的办案工作台、一张常驻桌面的案件卡片（可选）、一个起好手的案件工作区，以及第一份出好的文书。

**全程你只在 Codex 里说话。** 装东西、建目录、改设置都交给它去做，你不用打开终端、不用记命令。下面每一步给的都是「你对 Codex 说的一句话」，照抄进去就行，它怎么做是它的事。

**碰到跟这里写的不一样的，停下来记一笔，别自己修、别自己装东西补**，见最后一节。

对应版本：skills `0.7.0`。抄件会漂，正文里的事实以仓库里的原件为准：七件 skill 的名字见 `README.md`，起手的一问二选见 `skills/engineering/setup-case/SKILL.md`，办节点的打法见 `skills/engineering/doit/SKILL.md`，卡片的装法见卡片仓库 `loo0ng-widget` 的 `README.md`。

---

## 第 0 步　先看这台机器够不够格

打开 Codex，说这一句：

> 开工前帮我查一遍这台机器：macOS 是几点几、`python3` 是哪个版本、`node` 和 `npx` 在不在、磁盘还剩多少。查完逐条告诉我，**哪一条不够就先停下来说，别自己动手装东西补**。

四条的要求是：

| 查什么 | 要求 | 不够会怎样 |
| --- | --- | --- |
| macOS | **14 以上** | 桌面卡片的宿主装不上（第 2 步整步做不了）。升级系统是你自己要拍板的事，先告诉开发者 |
| `python3` | **3.9 以上** | 出件的脚本跑不起来（第 4 步卡住） |
| `node` / `npx` | 在，且能跑 | 第 1 步那条安装命令根本发不出去 |
| 磁盘可用空间 | 至少几个 GB | 装宿主与依赖会中途失败 |

**四条都够了再往下走。** 这一步是这份指南里唯一一个"不通过就不要继续"的关口：后面每一步都默认它过了。

---

## 第 1 步　装工作台（七件 skill）

打开 Codex，说这一句：

> 为我安装 https://github.com/f4de01/loo0ng-skills 的 skill，七件全装，装给我自己用。装之前先看看这台机器上 python3 是不是 3.9 以上，不是就先告诉我、别硬装。

它装完之后，**验一下**：新开一个 Codex 会话，打

```
$setup-case
```

它应当认出这个入口并开口说话（多半是说当前目录还不是案件工作区，这是对的）。打出 `$` 之后客户端能补全出 `setup-case` 就更明确。

**认不出来就停在这里记一笔**，别让它换别的办法硬装。

以后要升级，对它说一句「把 loo0ng-skills 更新到最新」。

> 它要是不知道该怎么装，把这一条给它：`npx skills@latest add f4de01/loo0ng-skills -a codex`。这是这套工作台在 mac 上唯一走通过的装法。

## 第 2 步　装桌面卡片（可选，建议装）

卡片是一张常驻桌面的小窗口，把你在办的几个案子并排列出来：每案的当前模块、进度、下一个要办的节点。它**只读不写**，不装也不影响上面那七件。

> ⚠️ **宿主要 macOS 14 以上**（第 0 步查过了）。装的过程 2026-09-19 在一台 mac 上走通过一次，但卡片里真的列出案件这一段还没有人验过：卡片里一个案子都不出现属于已知可能，记一笔交给开发者，别让它绕路自己想办法。

**先确定一件事：你的案子都建在哪。** 从第 3 步起，每个案子都是你在客户端里新建的一个**项目**，客户端会把这些项目放在同一个文件夹下。卡片要扫的就是那个文件夹。先对 Codex 说：

> 客户端新建项目时，项目文件夹默认建在哪个目录下？把那个目录的完整路径告诉我。

记下它回的那个路径，下一句要用。

> 装一下桌面卡片 https://github.com/f4de01/loo0ng-widget ，照它 README 里 mac 那条命令装。它要的宿主 Zebar 也一起装上。装完帮我建 `~/.loo0ng/卡片设置.json`，根目录填 `<上一句问出来的那个路径>`。
> **已经有这份设置就不要覆盖，把新的一条加进去。** 也不要替我新建任何"案件"文件夹。

那个「根目录」就是你所有项目的上级文件夹。卡片扫它**下面一层**：这一层里的每个文件夹，只要是案件工作区，就是卡片上的一行。可以填多个。

装完之后**有两件事得你自己点**（Codex 点不了菜单，也点不了系统设置）：

1. **打开卡片**：mac 菜单栏里找到 Zebar 的图标，进 `Widget packs` → `loo0ng` → `案件卡片` → `Run '默认'`。列表里没有就让 Codex 把 Zebar 重启一次。卡片会出现在程序坞里，最小化之后从那里还原。
2. **给它读文件夹的权限**：如果你的项目放在「文稿」「桌面」「下载」这三个文件夹里的任何一个下面，macOS 默认不让别的程序读它们。卡片会因此列出「根目录读不出」。去 `系统设置 → 隐私与安全性 → 文件与文件夹`，找到 **Zebar**，把对应那个文件夹的开关打开；找不到 Zebar 这一项，就先按第 1 点把卡片打开一次再回来看。

**以后每起一个新案子，你不用再碰这份设置**（新案子就建在同一个根目录下，卡片自己会扫到）。只有当你把案子建到了别的地方，起手的回显里才会出现一句「桌面卡片没在看…」，照那句话让 Codex 把那个目录加进去就行。

## 第 3 步　起手第一个案子

1. **在客户端里新建一个项目**，名字就用这个案子的名字。

   **一案一个项目，项目目录就是这个案子的工作区。** 这一步不要自己去建文件夹、也不要把工作目录切到别处：起手认的是当前目录，而客户端新建项目时已经把当前目录定好了，这正是它该在的地方。

   > 已经有一个在别处起过手的老案子要接进来？一样先在客户端里新建一个项目，再让 Codex 把老文件夹里的**全部内容**搬进这个新项目目录。整个搬没有副作用，图和索引里记的都是相对路径。

2. **打起手**：

   ```
   $setup-case
   ```

3. **它只问你一件事**：空图起手，还是用哪一份预设图。出厂带的那份叫 **破产**：12 个模块、72 个节点，外加 19 件空白模板。第一个案子建议就用它。回一句「用破产那份」即可；你在第一句里就说了（`$setup-case 用破产那份`），它不会再问。

4. **它会落下这些**，不用你做什么：

   ```
   <案件文件夹>/
   ├── 图.json  图视图.md  图视图.json   ← 这一案的台账与两份视图
   ├── 待归档/       ← 你原先丢在这个文件夹里的东西，全挪到了这里
   ├── 材料/
   ├── 参考/模板/  参考/指南/
   └── 文书/        ← 出件时才长出来
   ```

5. **最后它给你一张起手清单**：待归档里每一件它建议归到哪一格，等你一句话拍板。你可以说「都按建议来」，也可以说「第 3 条不要」「4 归材料」。**说了它才动**。没有文件要归就没有这一张。

6. 装了卡片的话，这时回显里会多一行「桌面卡片在看 …」，说明这一案卡片看得见。要是写的是「桌面卡片没在看 …」，照那句话让 Codex 把那个目录加进设置；没装卡片就两行都没有，正常。

起手一案只做一次。做完这一步，这个案子就成型了。

## 第 4 步　办第一个节点

**一个对话办一个节点。** 起手那个对话到此为止，下面开一个新的（仍然在这个案件文件夹里）。

1. **出一版**：

   ```
   $doit 出一版 管理人承诺书及团队人员
   ```

   节点标题照图里的写；记不住就先问路（见下一节）。它会照空白模板出一版，落在 `文书/<模块>/<节点>/` 下面，同目录还有一份审查报告。

2. **黄色的地方是留给你的**。收尾时它会说这一版黄色标在哪几处。用 WPS 打开就行，不需要 Word。两条路，随你：

   - **在 WPS 里直接填**：把黄色处写上，去不去掉黄色都行。
   - **在对话里告诉它**：把事实说给它，同一个对话里再打一次 `$doit 出一版 <节点>`，它重出一版。**你自己填过的字它一个不碰**，只动仍然黄着的地方和你点名要改的地方。

3. **拍板**：

   ```
   确认 管理人承诺书及团队人员
   ```

   这一句**在哪个对话说都行**：你在 WPS 里填完，隔几天新开一个对话说这一句，照样算数。黄色清光不等于办完，**办没办完只由你这一句话说了算**。

4. **下一个**：拍板之后它那一行直接给你下一句该打的命令（`$doit 出一版 <下一个节点>`），复制、开新对话、贴进去。

## 常用的几句

| 你想干什么 | 打什么 / 说什么 |
| --- | --- |
| 这案走到哪了、下一步做什么 | `$ask-loo0ng`（后面跟一句自由的话也行） |
| 这份我自己写好了 | `$doit <节点> 我自己写好了` |
| 这个节点本案不办 | `$doit <节点> 不适用`；整块不办：`$doit 模块 <模块> 不适用` |
| 法院退回要改一版 | 对已确认的节点再 `$doit 出一版 <节点>`，点名要改哪几处 |
| 图里没有我要做的事 | 还是 `$doit 出一版 <你说的标题>`，它把节点建进图再出件 |
| 把一堆文件整理进本案 | 在对话里说一句「把那个目录整理进来」「归一下待归档」 |
| 加个节点、改标题、挪模块 | 在对话里说一句「加一个节点 X」「把 X 挪到 Y 模块下」 |
| 把这一案的图留给下一案用 | 在对话里说一句「把这个案子的图存成预设图叫 <名>」 |

打法只有一个形状：**`$` 加裸名**，不带前缀（是 `$doit`，不是 `$<插件名>:doit`）。后面跟的话怎么说都行。

## 出问题了怎么办

**别自己修、别让它绕路自己想办法、别改工作台的文件。** 记三样交给开发者就够了：

1. 你说的那一句（原样）；
2. 它回的那段话（原样，报错整段都要）；
3. 当时在哪个文件夹、哪一步。

案件内容不用抄给任何人：把节点标题写成「某某节点」就行。

## 已知的几处毛病（都在修的名单上）

- 卡片**只认当前的图格式**。更早以前起手的老案子会被列进「读不出」那一行，**这是正常的，不用管它**：那一案照你原来的办法办完就行，工作台不接它。**别对它打起手**：起手会把那个案子里已经归好的材料与文书全挪进 `待归档/`。以后每个新案子都在客户端里新建项目、打一次起手，就不会再有这种图。
- 卡片只扫根目录**下面一层**。案子如果套在更深的层里（比如「根 / 分组 / 案件 / 版本」），卡片看不见它，界面上也不会提示。
- 卡片默认大小下，底部那个「扫一次」按钮和状态行要往下滚才看得见；它本来就每 5 秒自己刷新，不点也行。
- 装卡片之前就已经起手的案子，不会自动进卡片，得手工把它们的上级目录补进 `~/.loo0ng/卡片设置.json`（对 Codex 说一句让它加也行）。
