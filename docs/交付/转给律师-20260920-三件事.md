## 第二件　拿一个真案子从头跑一遍

这一件才是正经办案。细节照《上手指南》第 3、4 步，这里只列要打的几句。

1. **在客户端里新建一个项目**，名字就用这个案子的名字。

   一案一个项目，项目目录就是这个案子的工作区。不要自己去建文件夹、也不要把工作目录切到别处。

2. **在这个项目里打开 Codex，打起手**：

   ```
   $setup-case 用破产那份
   ```

3. **它最后会给你一张起手清单**：待归档里每一件建议归到哪一格，等你一句话拍板。你可以说「都按建议来」，也可以说「第 3 条不要」「4 归材料」。**说了它才动。**

4. **新开一个对话**（仍然在这个案件文件夹里），办第一个节点：

   ```
   $doit 出一版 管理人承诺书及团队人员
   ```

   节点标题照图里的写。记不住就先打 `$ask-loo0ng` 问一句「这案走到哪了」。

5. **黄色的地方是留给你的**。用 WPS 打开填，或者把事实在对话里说给它、再打一次 `$doit 出一版 <节点>` 让它重出。**你自己填过的字它一个不碰。**

6. **填完拍板**（这一句在哪个对话说都行）：

   ```
   确认 管理人承诺书及团队人员
   ```

**要发回来的**三处回显，原样：

1. 起手的完整回显，包括最后关于桌面卡片的那一行；
2. 出一版收尾时它说「黄色标在哪几处」的那一段；
3. 拍板之后它给你的下一句命令那一行。

节点标题、当事人、文件名写成「某某」就行，真内容一个字都不用抄。
