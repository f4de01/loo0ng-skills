## #40　`$` 提及是裸名

律师截图为据，三处一致：

- Skills 侧边栏列出六件，**均无冒号前缀**
- 输入框打 `$loo` 后补全出六件，同样无前缀
- 发 `$loo0ng-doit 你好` 触发成功，客户端附上 `<skill>` 块：`<name>loo0ng-doit</name>`、`<path>~/.agents/skills/loo0ng-doit/SKILL.md</path>`、front matter 与正文

与开发者 2026-09-07 的裁定一致，`ask-loo0ng`（#33）的入口表不用改。

**一条要补进入口表的细节**：只打 `$` 时列表很长（`Deep Research`、`Documents`、`Douyin Analysis`、`Lark *` 等二十余项），六件 `loo0ng` **不在首屏**，要再打 `loo` 才筛得出来。路由回复里给「下一句该打什么」时，写整串 `$loo0ng-doit …` 即可，律师照打不受影响；但若要教他从补全里选，得说清先打 `$loo`。

安装链：`~/.agents/skills` 是客户端与 CLI 共用的目录，六件都在。

## #41　这台机器上没有可用的渲染通道

### 路线一：`wpscli` 不能转 docx

`/Applications/wpsoffice.app/Contents/MacOS/wpscli` 存在，`--help` 退出码 0，是一个**纯 PDF 工具箱**。`convert document formats` 一组全部是从 PDF 转出（`pdf2word`、`pdf2excel`、`pdf2ppt`、`pdf2md`、`pdf2txt`、`pdf2imgpdf`、`pdf2cad`、`pdf2photo`）或图片 / CAD 转入（`photo2pdf`、`cad2pdf`）。**没有 doc2pdf、docx2pdf、word2pdf 之类的子命令。**

三种常见写法均报 `Error(200): Invalid subcommand`，退出码 200。

（附带一条与本项目无关的观察：`wpscli install` 的说明是 "Install AI agent skill to detected local agent directories"，WPS 自己会往 agent skill 目录写东西。）

### 路线二：WPS 的 AppleScript 只有最基本的几个动词

`Info.plist` 里没有 `NSAppleScriptEnabled` 与 `OSAScriptingDefinition`，bundle 内没有 `.sdef`；`sdef` 工具本身要 Xcode（该机只有 Command Line Tools），三条 fallback 都没抓到字典。

逐条实跑（每条独立 `osascript -e`）：

| 动词 | 结果 |
| --- | --- |
| `activate` | 退出码 0，认 |
| `open`（两种路径写法） | 退出码 0，均返回 `missing value` |
| `count of documents` | `“every document”不理解“count”信息。 (-1708)` |
| `name of front document` | `不能获得“name of document 1”。 (-1728)` |
| `save ... in ... as "PDF"` / `save ...` | `“document 1”不理解“save”信息。 (-1708)` |
| `save as ... file format format PDF` | `-2740` 语法错（术语不存在） |
| `export ... to ... as "PDF"` | `-2740` 语法错 |
| `compute statistics` / `repaginate` | `-2740` 语法错 |
| `count of pages` | `“pages of document 1”不理解“count”信息。 (-1708)` |
| `print front document` | 退出码 0，无输出 |

**结论：WPS 响应 Standard Suite 里最基本的 `activate` / `open` / `print`，但没有文档对象模型（`document` 不理解 `count`、`save`、`close`），也没有任何导出动词。** 两件样例都没出 PDF。

`print` 退出码 0 但无输出，是唯一还没走死的缝：macOS 的打印管线能「另存为 PDF」，但那一步在打印对话框里，属于 GUI 交互。本票不测这条。

### 对 ADR-0006 的直接后果

律师在自己那台 Mac 上办案出件，门禁就在他机器上跑。`gate.py` 的 `render_pdf` 只认 `powershell.exe` + Word COM，找不到就 `CannotRun` 退出码 2，而 ADR-0006 是 fail-closed、明写不降级。

这台机器上 Word、LibreOffice 都没有，WPS 的两条自动化路都不通。**「出一版」在他那里恒定拿不到文书。** 这落在 #41 写死的第三条分叉上：起地图，重开 ADR-0006 的 fail-closed 立场。

## 实测包自身的三个毛病（供下次修）

1. **第 1 级安装误判成功。** `npx skills add` 退出码 1、报 `Authentication failed for https://github.com/...`，脚本却写出 `==> 第 1 级成功，路线：1-skills.sh 网络装`。原因是 `装上了()` 只看 `~/.agents/skills/loo0ng-doit` 存不存在，而**上一轮拷进去的还在**（律师删了桌面上的包，没删 `~/.agents/skills`）。

   连带后果：这一轮根本没重新拷，用的还是上一轮带 CR 的旧文件，所以「四件 `name` 行尾带 CR」不是没修好，是**这次压根没覆盖**。打包侧的 LF 统一是有效的，只是没走到那一步。判据要改成比对内容或时间戳，不能只看目录在不在。

2. **`cat -A` 在 macOS 上不存在**（BSD cat），第 1 步的抽查命令三次都报 `cat: illegal option -- A`。要换成 `cat -v -e -t` 或 `od -c`。

3. `codex debug prompt-input "hi"` 的 `loo0ng` 过滤没命中、退出码 1；这条这次没拿到有用信息，模型侧的名字靠律师的截图坐实。
