# 律师机实测结论：0.7.0 装上之后，四段一次走通

2026-09-20（那台机器的时钟是 +08:00，卡片截图上写的是 09-21 13:23），远程做的：开发者在这边下指令，律师在他那台 mac 的客户端里照打，把回显原样贴回来。清单见 `docs/交付/转给律师-20260920-三件事.md`。

**证据等级先说清。** 这一趟**没有退出码**：律师是在客户端对话里操作的，客户端不显示退出码。有的是**贴回来的回显原文**与**一张卡片截图**（截图本身不入库，硬边界 1）。所有案件名在本文一律写成「某某」。上一趟（`docs/实测/mac-20260909/结论.md`）的局限是"只剩口述"，这一趟四段各有可引的原文，好于那一次，仍不如探针脚本那种带退出码的记录。

## 段 2　起手：在客户端新建的空项目上跑通

工作区是客户端新建的项目（ADR-0031），落在「文稿」下面某个项目根的下一层。回显原文：

```
出厂预设图「破产」：12 个模块、72 个节点，模板 19 件；模板整份拷进 参考/模板/，指引手册留在包内给开发者导入用
已按预设图 破产 整份起手：12 个模块、72 个节点，空白模板与时限句一次到位
工作区根上没有要挪进 待归档/ 的东西
点开头的 1 项没动（工具自己的东西）：.git
目录形状已建：待归档、材料、参考/模板、参考/指南、文书
已从预设图拷 19 件空白模板进 参考/模板/
已写 AGENTS.md
已写 CLAUDE.md
两份视图已随图落下：图视图.md、图视图.json
桌面卡片在看 <项目根>，下一轮扫描就能看见这一案
```

由此坐实三件：

1. **位置闸没有误伤**：项目落在「文稿」下面一层，闸拦的是「文稿」本身。
2. **客户端新建的项目里带一个 `.git`**，起手照规矩没动它。
3. **卡片的只读校验第一次说出了「在看」**（ADR-0032）。

### 「授权窗口」要正名

改 `~/.loo0ng/卡片设置.json` 那一步，律师贴回来的是「系统授权窗口问的是：是否允许我先把…备份…再改…」。那**不是 macOS 的隐私弹窗，是客户端自己的命令批准框**（写工作区之外的文件要人点一下）。读那份文件不弹（段 2 的起手只读它，一声没吭就读到了）。

所以 ADR-0032 的理由这样记才准：**写包外要过一道批准，而起手是在子进程里写，批不到就只能失败**。macOS TCC 那一层这一趟**没有**证据。

## 段 5　打开与拍板：链条走到头

**打开**：截图上那一版在客户端的文档预览里打开了（51% 缩放），正文渲染正常，**19 处黄色肉眼可见**，落在「XX（债务人名称）」「XX年X月X日」「（20XX）」这些位置上，与收尾清单对得上。预览窗右上有 WPS 的「打开」按钮，但**是否用 WPS 本体打开过，没有明证**，本文只记到「预览里打开了、黄色在」。

同一张截图还顺带记下两件：出件那一轮「已编辑 2 个文件」，差量 JSON 落在 `/private/tmp/` 下（macOS 上 `/tmp` 的实体），审查报告 `+59` 行。

**拍板**：打一句「确认 管理人承诺书及团队人员」，18 秒回：


至此 **装 → 起手 → 卡片 → 出件 → 拍板，五段全部有回显**。
