## What it does

`filing` 把文件归进本案。来源两种，去向三格。

**来源两种**：`待归档/` 里的（**移动**），或你指的任意一个目录、包括工作区外的（**只复制，原件一字不动**）。

你发起整理时，**搬之前先给你一张清单**：文件、去向、一句理由；同名不同内容的与拿不准的单列一段，你一句话拍板才搬。

工作区根另有一份**归档索引**（`归档索引.md`），一行一件：路径、一句话这是什么、归档日期、文本列。出一版开场先读它，再决定读哪些原件。

## When to reach for it

模型会在你要整理文件时调用它，你不用记名字。在对话里说一句就行：「把那个目录整理进来」「归一下待归档」「这几份新收到的材料归档」。

另有两处由别的 skill 驱动：起手末尾清一次待归档（进起手清单，一次拍板）；出一版开场清一次待归档（**不问、不出清单**，回显一行带过）。

## Prerequisites

会话当前目录是案件工作区（有 `图.json`）。工作区外的来源目录要真在，且不能指进工作区、也不能套着工作区。脚本只用 Python 标准库，跑得动 python 3.9。

## 三格按用途分，去向由模型判

同样是一件文档，已经填好的事实材料、待填写的空白模板、规定该怎么办的指南，用途不同，放的位置也不同。模型读内容来判断去向，并把理由写进清单；搬文件的脚本只执行计划，不替模型判断。

| 这件东西是 | 去向 |
| --- | --- |
| 本案的事实来源原件（合同、账、函、笔录、照片、压缩包） | `材料/` |
| 空白件（官方表格、格式文本，所里自己做的也算） | `参考/模板/` |
| 本案适用的官方要求文件（法院的通知、指引、材料清单） | `参考/指南/` |
| 三格都没有正向证据 | 留在来源处，回显里说一句为什么拿不准 |

归档进模板格，不会自动给节点挂上模板；归档进指南格，也不会自动往图里加节点。三格先把文件的用途分清，出一版时再通过归档索引找到要读的原件。

## 不改名、不覆盖，重复按内容认

**文件名与子目录相对路径原样保留**，归档不会给冲突文件自动加后缀。是不是同一份东西按内容判断：即使换了文件名，只要三格里已有相同内容，就报「已有」而不再搬；一次计划里两份相同内容也只搬第一件。

同名与重复是两回事。清单里的「重名」提示本案已有同名文件，让你决定是否放到别处；真正要落的目标路径若已被不同内容占用，才报「同名冲突」，那一件留在来源处，其余可归档的照搬。归档索引只记真搬进来的文件，因此回显说命令完成，还要看已归档、已有、同名冲突各有几件。

## Common questions

**同一份材料再给一次，或同名但内容不同，会怎样？**
按内容去重，本案已有就报「已有」，不搬第二遍。同名不同内容先单列给你定去向；目标路径仍被占用时，那件留在原处，不改名、不覆盖。出处：[CHANGELOG 0.6.0，归档加强](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

**以前一条一文件的律师陈述去哪了？**
这套机制已退场，归档不再记录陈述的性质、取代与标题。你在对话里给出的本案事实由 `doit` 在填进文书后，按日期、原话追加到 `材料/律师说过的.md`；`filing` 不写这份文件。出处：[CHANGELOG 0.6.0，律师陈述退场与办节点重写](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

## It's working if

- 你发起整理时，搬之前先看见一张清单，说了那一句才动；出一版开场清场只回显一行。
- 归档之后 `归档索引.md` 里每件真搬进来的都有一行；「已有」与「同名冲突」不写行。
- 工作区外的来源目录里，原件一个字节没变。
- 计划不合法或越界时**整条拒绝、一件不搬**，而不是搬一半。
- `图.json` 与两份视图一字不动。

## Where it fits

归档只搬文件，**不写图**：追加条目与改图的构成走 [graph](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/graph.md)。它在起手（[setup-case](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/setup-case.md)）与出一版（[doit](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/doit.md)）的流程里各被调一次。归档进 `参考/模板/` 的空白件挂到哪个节点上由 [graph](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/graph.md) 记，从指南提节点是 [domain](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/domain.md)。问在哪、下一步做什么是 [ask-loo0ng](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/ask-loo0ng.md)。
