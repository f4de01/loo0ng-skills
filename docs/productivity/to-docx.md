## What it does

`to-docx` 照空白模板填一份 DOCX，**在 docx 原件上原地施加改动，模型不重写整篇**。

代码先把模板（或这个节点当前的文书）打成一份**带编号的清单**：每段一行，槽、模板自带的高亮、说明段都标出来。模型只提交编号处的改动，只有五种：填、按原文换、删段、加高亮、去高亮。代码在 docx 原件上原地施加并直接落盘。

## When to reach for it

多数时候你不必点它的名字：出一版时 [doit](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/doit.md) 会调它。你直接用得上的两句：

- 「**这份模板有哪些槽要填**」：清单能单独对任意 DOCX 打，一处一行、`p<编号>#<槽号>` 起头、末尾报总数；你下一句点名要改哪一处，用的就是这个编号。
- 「**这稿子帮我填一下**」：它填完写到临时位置并打印路径，不进 `文书/`、不写审查报告、不动图。

在 Word 里填过黄色处之后说「重出」，也是它在跑。

## Prerequisites

Python 3.9 或以上的解释器，以及 `python-docx==1.2.0`；随 skill 分发的 `requirements.txt` 精确钉住这个依赖版本。**怎么弄到能 `import docx` 的环境归模型，没配过 python 不得阻断出件**；需要安装时，依赖只装到临时位置，不进案件工作区、skill 目录或用户全局环境。版本对不上照常出件，回显那一行会明写它不是钉住的那个版本。

## 差量只写要改的那几处

清单上的 `p2#1` 指的是第 2 段的第 1 个槽。材料能确定这一处，就交这一处的填法；其余位置不必重新抄一遍。**差量是一组有坐标的改动**，每一条都能回到清单上指出它改了哪里，代码据此在原件上施加，保住文书骨架、表格几何与槽外的格式。

第一次出件以空白模板为载体，另存到文书路径，空白模板只读；重出以当前文书为载体，覆盖同一份文书。这里的「原地施加」说的是改动落在载体原有的位置，并不意味着覆盖空白模板。差量写坏会整件拒改，已有文书一个字不写，修好差量再来。

保住表格结构不等于保证填完后的页数与排版。字变长仍可能撑列、多出空白页；出件后你在 WPS 里打开看，一句「写短点重出」就修了。代码不对文书合不合格下判断。

## 留黄把缺口交给律师

**黄色只有一个意思：「这里要律师动手」。** 材料里没有的值不编，那个槽不写进差量，代码在施加收尾时统一留黄；元数据（作者、最后修改者、上次打印时间）也在此时无条件清掉。

| 这一处的情况 | 黄色怎样处理 |
| --- | --- |
| 槽没有填，包括填了空串 | 代码统一留黄，模型不必逐处补标记 |
| 模型写了但没把握 | 模型显式加黄，交给你判断 |
| 模板自带的高亮 | 解决了才显式去黄，没解决的继续留着 |

出件回显里的**高亮清单**逐处记下原文与位置，随审查报告留下。下次你填过黄色处再说「重出」，模型对照这份记录认出哪些是你填的，保留你的文字；填过但没去掉的黄，只去黄。清单因此既是这次交给你的待办，也是下次重出的依据。

## Common questions

**Word 里填过的黄色处，重出时怎么保住？**
以当前文书为底，对照上一版审查报告的高亮清单：你填了但没去黄的只去黄，已去黄的不碰，仍待填的与点名处才写差量。段落号可能因插段而变，模型还要按记录的整段文字或表格坐标认位置。报告只有「律师自写」时，没有旧高亮清单，当前黄色不动，只改点名处。出处：[#14，重出比对](https://github.com/f4de01/loo0ng-skills/issues/14)、[CHANGELOG 0.6.0，办节点重出与兜底登记](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

**版式门禁和「需人眼」结论去哪了，还能说「检一下」吗？**
门禁整件已删，「把这份 DOCX 检一下」不再是这件 skill 的用法。撑列、页数、空白页由你在 WPS 里看，代码只保住施加时的结构与格式、拒绝非法差量、清元数据、给未填槽留黄，不再下文书合格结论。出处：[#22，门禁退场](https://github.com/f4de01/loo0ng-skills/issues/22)、[CHANGELOG 0.6.0，门禁退场](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

**Markdown 转 Word 那条路还在吗？**
不在，Markdown 最小集与冻结转换器已退场。现在先给一份 DOCX 空白模板，打出带编号的清单，再提交填、按原文换、删段、加高亮、去高亮这五种差量，由代码施加到原件结构上。出处：[CHANGELOG 0.6.0，to-docx 换成填模板](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

**没有门禁了，为什么还会「拒改」？**
拒的是差量本身：编号越界、要换的原文不唯一、区间重叠，或槽所在 run 含脚注引用、图片、域代码。整件拒改时已有文书一个字不写；按提示修差量至多重来 2 次，仍拒则本次生成失败，可兜底自写。合法的重出直接覆盖同一份文书，不再需要 `--overwrite`。出处：[#22，保留拒改与重试、移除覆盖旗标](https://github.com/f4de01/loo0ng-skills/issues/22)、[CHANGELOG 0.6.0，门禁退场与施加构造](https://github.com/f4de01/loo0ng-skills/blob/main/CHANGELOG.md#060)。

**模型会不会误去掉我自己加的黄？**
会。在曾记录高亮的段落里新加的黄，模型可能当成已经填过而去掉；没有占位标记的提示文字或没把握的句子，误去黄后代码兜不住。仍是占位形状的槽会由施加收尾自动补黄，所以不能把「黄色清零」当成确认。出处：[#14，明确记录的误去黄局限](https://github.com/f4de01/loo0ng-skills/issues/14)。

**审查报告第三段为什么换成「施加原话」？**
门禁退出后，这一段记录代码实际做了什么：施加回显原样抄入，包括改动、留黄及发生过的拒改与重来次数。报告保留生成依据、高亮清单、施加原话、时限推算四段，供留痕和下次重出，不要求律师先读它才能拍板。出处：[#14，审查报告四段](https://github.com/f4de01/loo0ng-skills/issues/14)、[#22，第三段改名](https://github.com/f4de01/loo0ng-skills/issues/22)。

## It's working if

- 出件前后，表格的骨架与槽外的格式逐字节不变。
- 没填的槽全是黄的，一处不漏；元数据每次都被清掉。
- 差量不合法时退出码 1，`--out` 指的已有文书原样不动。
- 重出之后，你上一次填过的每一处文字都在，该去的黄去了。
- 回显末尾的「高亮清单」逐处给出段落号与原占位：那就是收尾告诉你的那几处。

## Where it fits

它是七件 skill 中唯一住在 `productivity/` 的一件，**离开案件工作区也能单独用**：对任意 DOCX 打清单，或把指定稿子填到临时位置，都不需要先建图。

它只施加，**不决定写什么**：材料、指南、空白模板与同模块在前已确认文书的整读，以及差量的内容，都由 [doit](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/doit.md) 负责；缺的事实照留黄，不停下来问。空白模板住 `参考/模板/`，起手时由预设图整份拷入（[setup-case](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/setup-case.md)、[domain](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/domain.md)）；往图里追加生成条目是 [graph](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/graph.md)；归档是 [filing](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/filing.md)。它**不对文书合不合格下任何判断**：那归你在 WPS 里的眼睛。问在哪、下一步做什么是 [ask-loo0ng](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/ask-loo0ng.md)。
