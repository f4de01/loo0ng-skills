## What it does

`to-docx` 照空白模板填一份 DOCX，**模型不重写整篇**。

代码先把模板（或这个节点当前的文书）打成一份**带编号的清单**：每段一行，槽、模板自带的高亮、说明段都标出来。模型只提交编号处的改动，只有五种：填、按原文换、删段、加高亮、去高亮。代码在 docx 原件上原地施加并直接落盘。

这么做保住三样：骨架、表格几何与槽外的格式由构造保住；**删句、抹掉法院名、编一段事实在结构上做不到**；差量写坏就整件拒改、一个字不写。**没填的槽由代码统一留黄**，元数据（作者、最后修改者、上次打印时间）收尾无条件清掉。

**没有门禁**：撑列、页数、空白页这类由填进去的字多长决定的几何，你出件后本来就在 WPS 里打开看，一句「写短点重出」就修了，代码不替你判。

## When to reach for it

多数时候你不必点它的名字：出一版时 [doit](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/doit.md) 会调它。你直接用得上的两句：

- 「**这份模板有哪些槽要填**」：清单能单独对任意 DOCX 打，一处一行、`p<编号>#<槽号>` 起头、末尾报总数；你下一句点名要改哪一处，用的就是这个编号。
- 「**这稿子帮我填一下**」：它填完写到临时位置并打印路径，不进 `文书/`、不写审查报告、不动图。

在 Word 里填过黄色处之后说「重出」，也是它在跑。

## Prerequisites

一个能 `import docx` 的解释器，且是钉住的那个版本（`requirements.txt` 精确钉 `python-docx==1.2.0`，随 skill 分发到你的机器）。**怎么弄到它归模型，没配过 python 不得阻断出件**；装出来的东西只落在临时位置。版本对不上照常出件，回显那一行会明写它不是钉住的那个版本。

## Common questions

**它会不会改掉我在 Word 里填过的地方？**
不会。说一句重出时，它读当前清单、对照上一次审查报告里的高亮清单逐处判：你填了没去黄的，它只去黄、文字一个不碰；你填了又去了黄的，不写、不碰；只有仍是黄色的地方与你点名的位置才写差量。**你改过的位置一律不查。**

**为什么有些地方填了还是黄的？**
黄色的意思只有一个「这里要律师动手」。没把握的句子模型会自己加黄；模板自带的高亮它解决了的才去黄，没解决的留着交给你。

**「拒改」是什么意思？**
差量本身写坏了（编号越界、要换的原文在那段里不唯一、两处改动区间重叠），或者槽所在的位置含脚注引用、图片、域代码：切开会把它们复制、换字会把它们丢掉。这时整件拒改、一个字不写，你原有的那份文书原样不动。模型按提示改差量重来，至多 2 次；仍拒就是这一次生成失败，不交出半成品，你可以兜底自写。

**我的模板用的占位符不一样怎么办？**
`XX`、`（20XX）`、`XX年X月X日`、`【…】`、下划线串、带量词的单个 `X` 是自带的一张表，形状可加。

**审查报告里的「施加原话」是谁写的？**
代码的回显，照抄。模型对那一段没有写权：不删行、不重排、不在回显之外补一句结论。

## It's working if

- 出件前后，表格的骨架与槽外的格式逐字节不变。
- 没填的槽全是黄的，一处不漏；元数据每次都被清掉。
- 差量不合法时退出码 1，`--out` 指的已有文书原样不动。
- 重出之后，你上一次填过的每一处文字都在，该去的黄去了。
- 回显末尾的「高亮清单」逐处给出段落号与原占位：那就是收尾告诉你的那几处。

## Where it fits

它只施加，**不决定写什么**：材料、指南、空白模板与同模块在前已确认文书的整读，以及差量的内容，都由 [doit](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/doit.md) 负责；缺的事实照留黄，不停下来问。空白模板住 `参考/模板/`，起手时由预设图整份拷入（[setup-case](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/setup-case.md)、[domain](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/domain.md)）；往图里追加生成条目是 [graph](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/graph.md)；归档是 [filing](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/filing.md)。它**不对文书合不合格下任何判断**：那归你在 WPS 里的眼睛。问在哪、下一步做什么是 [ask-loo0ng](https://github.com/f4de01/loo0ng-skills/blob/main/docs/engineering/ask-loo0ng.md)。
