# 种子「整块不走」的状态

按真实的破产领域目录**空图起手**，再摆出：

| 模块 | 节点 | 状态 |
| --- | --- | --- |
| 接受指定与报备 | 管理人承诺书及团队人员 | 已确认 |
| 自行和解 | 和解协议 | 不适用 |
| 自行和解 | 裁定认可和解协议并终结破产程序的申请 | 不适用 |

模块级不适用由引擎把「自行和解」在领域图里的两个节点带进案件图、逐个记一条不适用
（原话「本案不走和解，自行和解那一块整个不办」），图仍是唯一台账，没有模块级标记。

案件图里没有未生成的节点；最近动过的模块是「自行和解」，它在领域图里没有剩下的节点。
路由该落在五问的问 4，最早的是「管理人工作计划」，并且**不再提**那两个和解节点。
