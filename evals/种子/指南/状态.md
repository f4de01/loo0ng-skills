# 种子「指南」的状态

在种子「图引擎」的状态之上（个人预设图「菜园」整份起手：4 模块 9 节点、都未生成），`参考/指南/` 里多一份 `种植指南.md`（合成的菜园地块管理要求，本案适用的要求文件），由跑器拷进 `待归档/`、回放经归档 CLI 搬进去，`归档索引.md` 有它那一行。指南里写了一个图里没有的模块「越冬」（节点「覆膜」挂表格「覆膜记录」并带一句时限、「清园」无表格且只说「及时」）、一个已有模块「养护」下图里没有的节点「施追肥」（带一句时限）、以及图里已有的「浇水」（同名，不该再提）。没有与图里相似不同名的标题，一句话拍板时不留待定。

供 skill "domain" 的用例「出雏形」：律师一句「从这份指南里提节点」，断言回显与拍板后的 `图.json`（案件图上时限只回显不写）。

不含隐私检查器五类正则能命中的值。
