## 为什么钉域代码

填模板脚本对「槽所在 run 含脚注引用、图片、域代码」无条件拒改（ADR-0024 第二类：切开 run 会把域复制、换字会把域丢掉，两样都是悄悄改坏文书）。这道检查两处都过：模型写的 `fill`/`replace`/`highlight` 落到那一段被拒；模型一个槽都不填，收尾统一留黄扫到那些槽也被拒。于是这个节点的任何一次施加都退 1、一个字不写，`doit` 那条「拒改就改差量重来至多 2 次，仍拒即生成失败：不落盘、不写审查报告、不追加条目」必然走到终点。差量怎么改都改不掉它：域代码在模板里，不在差量里；改模板是正文明令禁止的（改的是差量，不是模板规定的正文结构）。

**钉每一段而不是只钉一段**：只钉一段时，模型删掉那一段（`delete`）就绕过了检查、件照样落盘，而红出来的形状与「钉子落空」一模一样：旧种子「越界」在 #107 上栽的正是这一跤。钉满之后要脱身只剩「把每个带槽的段都删掉」，那是把正文删光，用例的断言看得出来。剩下一条 `--no-highlight-rest` 加空差量仍能写出一件空壳，正文没有这个用法，落盘即红。

ADR-0024 之前这一档由种子「越界」钉行高造门禁不通过；门禁整件退场后不通过没有了对象，换成这一件（#20）。回放末尾自己复核三次：空差量、填 p2#1、先删一段再施加，三次都得退 1 且 stderr 里有「域代码」、一个字都没写出来，否则钉子落空、回放失败。

供 skill "doit" 的用例「拒改收尾」：出一版这个节点，断言终态是生成失败且什么都没留下、模板没被改、回复交出拒改原文并提兜底。
