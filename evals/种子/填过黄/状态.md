# 种子「填过黄」的状态

一个模块一个节点（「接管」→「印章备案」，空白模板是官方模板 1-2），预设图由引擎自己在临时目录造出、整份拷入，目录形状照 ADR-0023（待归档、材料、参考/模板、参考/指南、文书）。skill "setup-case" 重做（#17）之前，回放直接调引擎起图，不经起手 CLI。

| 节点 | 状态 | 条目 |
| --- | --- | --- |
| 印章备案 | 已生成 | 生成 1 次（agent） |

agent 出过一版 `文书/接管/印章备案/印章备案.docx`：能填的都填了（值来自 `材料/律师说过的.md`），三处没材料由代码留黄：公安局名（「XXX」）、启用时间（表里的「XX年X月X日」）、落款日期（末尾的「XX年X月X日」）。审查报告 `印章备案-审查报告.md` 按四段写，高亮清单与施加原话是 apply 回显原话（`skills/in-progress/to-docx/references/审查报告.md`）。

之后律师在 Word 里动了四笔：

| 位置 | 律师做了什么 | 现在的样子 |
| --- | --- | --- |
| 启用时间（表里） | 填了「甲年乙月丙日」，**没去黄** | 文字变了、仍是黄 |
| 落款日期（末尾） | 填了「甲年乙月丁日」，**去了黄** | 文字变了、不是黄 |
| 公安局名 | 没动 | 仍是「XXX」、仍是黄 |
| 正文第一段之前 | 插了一段「律师补记：印模以刻章回执为准。」 | 段号整体后移一位 |

律师那几笔用 fill.py 的原语直接改 run 的文字与 rPr、不经差量，与 Word 里手改留下的 XML 同形；视图在律师动过之后重算过。

供用例「模型误去黄」：律师一句「重出」，断的是模型判对了哪处是律师填的（只去黄、不碰字），没动的仍黄，插的段原样在，没有节点被自动确认。

不含隐私检查器五类正则能命中的值：当事人、法院一律写「甲」「乙」「丙」，没有案号、手机号、身份证、统一社会信用代码、案件目录路径。
