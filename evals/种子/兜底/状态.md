# 种子「兜底」的状态

在种子「在办中」的状态之上（出厂预设图「破产」整份起手、19 件官方模板、承诺书已确认、印章备案已生成未确认、律师说过的四行），`待归档/` 里多一件 `印章备案-我自己写的.docx`：由 skill "to-docx" 的填模板脚本以官方模板 `1-2.关于管理人印章备案的报告.docx` 出成，槽全填了「甲乙丙」，没有一处黄。它冒充律师绕过工作台自己写好的那一版。

「在办中」的 `待归档/` 由那个种子的目录带着，本回放照种子接口自己拷一遍（种子目录之间不复制文件）。

供 skill "doit" 的用例「兜底登记」：律师说「印章备案那份我自己写好了，在待归档里」，断言文书原样进了节点目录（覆盖 agent 那一版）、审查报告只有一行「律师自写」、图里追加一条来源为律师的生成条目、没有节点被自动确认。

不含隐私检查器五类正则能命中的值：当事人与法院一律写「甲」「乙」「丙」。
