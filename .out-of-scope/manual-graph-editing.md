# 支持律师直接手改图.json

不把直接编辑 `图.json` 作为受支持的改图方式，也不提供由模型猜测手改意图、修补 JSON 以绕过引擎拒写的流程。

## 为什么不做

图引擎是图的唯一写入口。条目只追加、状态从条目算出、节点不删除等约束由这个入口守住；每次写入还会重算两份图视图。直接改 JSON 会绕过这些约束，视图也可能与图不一致。仅仅让 JSON 语法正确，不能证明案件状态与留痕仍然可信。

律师要新增节点、改标题、移动节点或标记不适用，直接说要做什么，由 `graph` 调引擎落盘并回显；查看进度读 `图视图.md`。这是现行正文支持的改图与读图方式。

引擎报「不合校验」时，按 `graph` 正文告知文件被手改过或损坏，让律师从上一次能用的状态重来。模型不自行修改 JSON 来消掉报错。

## 曾经提过

- 暂无，来自 ADR-0003；现行 `graph` 正文保留「律师手改 图.json 不受支持」及拒写后的处理方式。
