# 归档

案件工作区就是会话当前目录，`图.json` 是身份标记。本 skill 持一个 CLI：`scripts/archive.py`（Python 标准库，零依赖，不 import 图引擎）。

**判断归模型，搬运归代码。** 一件东西是什么、该去哪一格、一句话怎么描述它，只有读过它的模型知道；脚本只做确定性的那一半：不改名、不覆盖、按内容哈希去重、子目录相对路径原样、工作区外的只复制、索引一行一件。脚本不认任何领域语义，也不按扩展名替你判去向。

## 去向三格

| 这件东西是 | 去向 |
| --- | --- |
| 本案的事实来源原件（合同、账、函、笔录、照片、压缩包） | `材料` |
| 空白件（官方表格、格式文本，所里自己做的也算） | `参考/模板` |
| 本案适用的官方要求文件（法院的通知、指引、材料清单） | `参考/指南` |
| 三格都没有正向证据 | **不写进计划**，留在待归档，回显时说一句为什么拿不准 |

`材料` 下可按主题建子目录（计划里的「子目录」字段），另两格不分层。压缩包与照片原样归 `材料`，不解压、不识图。

## 三个进入点

| 谁发起 | 出不出清单 | 步骤 |
| --- | --- | --- |
| 律师一句话（「把这些归一下」「把某个目录整理进来」） | 出 | `list` → 写计划 → 回显清单 → **律师一句话拍板** → `apply` |
| 起手末尾（由 skill "setup-case" 调） | 出，并进起手清单一次拍板 | 同上 |
| 出一版开场（由 skill "doit" 调） | **不出，也不问** | `list` → 写计划 → `apply`，回显一行带过 |

**没有文件要归就没有确认点**：`list` 说「没有文件」就到此为止，不写计划、不调 `apply`、不出清单；`待归档/` 这一格不在也是这个答复，不是拒绝。工作区根上律师随手丢的文件由起手先挪进 `待归档/`，本 skill 只认 `待归档/` 与工作区外的目录两种来源。

## 怎么调

```
python <本目录>/scripts/archive.py list [--from <工作区外目录>]
python <本目录>/scripts/archive.py apply --plan <计划.json> [--from <工作区外目录>]
```

- 不给 `--from` 就是 `待归档/`，**移动**；给了 `--from`（必须在工作区外）就是**复制，原件一字不动**。工作区里除 `待归档/` 之外的目录不收。
- 计划是一个 JSON 数组，一条一件，`路径`、`去向`、`说明` 必填，`材料` 可另给 `子目录`；格式与样例见 [references/格式.md](references/格式.md)。计划文件写在临时位置（`%TEMP%` 之类），**不在工作区里建暂存目录**。
- 退出码 0 命令跑到底，1 整条拒绝（一件不搬、索引一行不写），2 用法错。`--help` 是参数的权威。

**完成判据**：`apply` 的回显在手，逐件结果（已归档、已有、同名冲突各几件）已读给律师。

## 清单怎么出

`list` 一件一行，制表符后是脚本按内容哈希算出的状态：

```
合同.pdf	新
扫描/照片.jpg	新
又一份通知.pdf	已有 → 参考/指南/通知.pdf
同名的.txt	重名 → 材料/同名的.txt（内容不同）
```

据此写给律师看的清单，三列加一段：**文件、去向、一句理由**；标「已有」的不写进计划，在清单末尾一句「另有 N 件本案已有，不再搬」；标「重名」的**单列一段**，说清已有的那份是哪一件，让律师定这一件还搬不搬、搬到哪。拿不准去向的也列在那一段里，说一句为什么。整张清单一次回显，等律师一句话，说了才 `apply`。

**「重名」是提示，「同名冲突」才是拦截。** `list` 的「重名」按文件名跨三格找，那时去向还没定，它只是让律师知道本案已经有一件同名的；律师说了搬到别处就照搬。`apply` 的「同名冲突」只在**目标路径**已经被占且内容不同时出现，那一件必不搬。

## 脚本自己守的规矩

拒了就照实转告，回显那几行照读给律师。

| 规矩 | 脚本行为 |
| --- | --- |
| 不改名 | 文件名与子目录路径原样；要改名是律师的事，脚本没有这个参数 |
| 不覆盖 | 目标路径已存在且内容不同：那件不搬、留在原处，回显「同名冲突」 |
| 去重 | 内容哈希与三格里已有的任一件相同：报「已有」不搬（跨格也算），同一份在一次计划里出现两回也只搬第一件 |
| 不越界 | 绝对路径、`..`、来源目录之外，以及 `--from` 指进工作区或套着工作区，一律**整条拒绝，一件不搬** |
| 计划不合法 | 缺字段、去向不是三格、说明含竖线或换行、字段不认得、同一件给两次、两条落到同一路径、指到目录，一律整条拒绝 |
| 律师说过的 | 目标是 `材料/律师说过的.md` 即拒；那份文件由 skill "doit" 追加，归档永不写它 |
| 图 | `图.json` 与两份视图一字不动 |

「已有」与「同名冲突」不是拒绝：命令照样退 0，那几件没搬而已，其余照搬。

## 归档索引

工作区根的 `归档索引.md`，一行一件，`apply` 每次把新件插在索引那张表的末尾、已有那一行原地改，已有行不重排；表外的段落与别的表一字不动（认得出的只有四列表头那一张表，表头不在就先补一张）：

| 列 | 写什么 |
| --- | --- |
| 相对路径 | 归档之后的工作区内路径 |
| 是什么 | 模型给的一句话，就是计划里的 `说明`（进表，别写竖线） |
| 归档日期 | 搬进来那天 |
| 文本 | 本版恒为「原件」 |

只有真搬进去的件才有行；「已有」与「同名冲突」不写行。出一版开场整读先读它，再决定读哪些原件。

## 不做的

解压、识图、OCR、PDF 转文本都不做，本版一件不转。后两样是后续版本，那时转出的文本放原件旁、同名加 `.md`，索引的「文本」列指向它；在那之前这一列恒为「原件」，不要手写别的值。

## 与邻居的边界

- 归档只搬文件，**不写图**：追加条目与改图的构成调用 skill "graph"。
- 律师在对话里给出的事实不经这里：由 skill "doit" 一行一行追加到 `材料/律师说过的.md`。
- `参考/指南/` 里的要求文件归档之后怎么用：整读在出件时由 skill "doit" 做，从指南提节点是 skill "domain" 的事。
- 空白模板归档进 `参考/模板/` 之后，哪个节点用哪一件由 skill "graph" 的空白模板属性记。
