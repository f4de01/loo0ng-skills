# 预设图的家

预设图是一份构建完成、没有条目、带着空白模板的图，起手时整份拷进案件工作区。本 skill 是它的家：按名与归属解析路径、分两组列出、另存、导入，并持有把一个来源变成图里模块与节点的那个机制：雏形。

两个 CLI（都是 Python 标准库，零依赖，不 import 图引擎）：`scripts/preset.py` 管两处预设图，`scripts/sketch.py` 管雏形。写图的那一步一律经 skill "graph" 的引擎子进程，它仍是图的唯一写入口。

## 两处两归属

| 归属 | 在哪 | 装什么 | 谁写 | 升级时 |
| --- | --- | --- | --- | --- |
| **出厂** | 本目录的 `assets/预设图/<名>/` | `预设图.json`、`模板/`（官方模板原件）、`指引手册/`（指引手册原文） | 开发者经 PR | 整个被换掉；**原位读，不拷出包** |
| **个人** | 律师本机 `~/.loo0ng/预设图/<名>/` | `预设图.json`、`模板/` | 律师一句话另存，开发者导入 | 碰不到 |

- **两处不合并，同名不并存**：另存与出厂重名即拒，让律师换个名字（起手的列表两组同名会混）。
- **出厂件谁都不许在会话里写**，开发会话也不行：引擎无条件拒，没有放行口。包一升级它就被整个换掉，写进去的东西静默消失。只读的用法一条不碎：`validate`、列表、起手 `--preset` 指着它整份拷入，全部照旧。
- **案件工作区不记路径**，只记名与归属（起手落在工作区 `AGENTS.md` 的指针块里）：包一升级绝对路径就死，路径每次按名与归属当场解析。
- `指引手册/` 只住在出厂那一处，给开发者导入用，**不拷进工作区**。

## 解析与列表

```
python <本目录>/scripts/preset.py list
python <本目录>/scripts/preset.py resolve --name <名> --owner 出厂|个人
```

- `list` 分两组回显，起手（skill "setup-case"）拿它给律师看那一问；两组都空就是「这次只能从空图起手」，照退 0。
- `resolve` 回一行绝对路径，第二行是规模。这个名与这个归属下没有就拒，**不猜、不回退到另一个归属**：律师说的名在另一处，回显里会点出来，让他确认要哪一份。
- 退出码 0 完成，1 拒绝，2 用法错；`--help` 是参数的权威。
- 下面几处要用到 skill "graph" 的引擎：它的 `--graph` 与 `--kind` 是**全局旗，写在子命令之前**（`graph.py --graph … --kind preset <子命令> …`）；本 skill 两个 CLI 的 `--kind` 反过来，写在子命令之后。

## 另存：律师一句话把本案的图存成个人预设图

律师说「这个案子的图存成预设图叫 Y」时，按顺序做：

1. **去案件化的标题先回显**。读 `图视图.md`，把标题里带当事人、案号、金额、具体日期的挑出来，一条一行写成「现在的标题 → 改成什么」，连同「其余照原样」一句，一次回显。挑不出来就说一句「标题里没有本案的东西，直接存」。
2. **等律师一句话**。这是本 skill 唯一的确认点。**未拍板不另存**：不跑下面那条命令，一个字不写。
3. **另存**：

   ```
   python <本目录>/scripts/preset.py save --name <Y> [--graph 图.json] [--templates 参考/模板]
   ```

   它经引擎剥掉全部条目与不适用记录，只留模块、节点、空白模板与时限；`参考/模板/` 整份拷进新预设图的 `模板/`；落在个人预设图那一处。与出厂重名拒、目标已存在拒，案件图一字不动。
4. **按律师的话改标题**：在**新的那份预设图**上逐条改，每条都调用 Skill 工具，传 "graph"：`graph.py --graph <新预设图>/预设图.json --kind preset rename-node --node … --title …`（模块用 `rename-module`）。**两个旗在子命令之前**，放到后面引擎不认。改的是预设图，**案件图上律师写过的标题一个字不动**。
5. 把 `save` 的回显与改过的标题照读给律师，末尾说一句往后起手怎么选它（归属「个人」，名 Y）。

**完成判据**：`save` 退出码 0，标题按律师的话改完，回显已读给律师。

## 导入：开发者从一个来源长出一份预设图

**只在开发会话里做，律师不可导入**（来源的形状定不下来，写死规则会错；产物要经 PR 与第二双眼才进仓库）。律师要复用整案的图，走的是上面的另存。

来源给示例，不写死规则：一棵按流程分层的目录树（每一层一个模块、每一份文书一个节点）、一份通用指引手册（`assets/预设图/<名>/指引手册/` 下的原文）、别的案件图（`图.json`，条目忽略、只看构成）。来源长什么样由你整读之后判断，下面只写机制。

1. **建一份空的个人预设图**：`~/.loo0ng/预设图/<新名>/` 下调用 Skill 工具，传 "graph"：`graph.py --graph <新名>/预设图.json --kind preset init --empty`。名与出厂重名就换一个。
2. **整读来源**。docx 调用 Skill 工具，传 "to-docx"，打成纯文本（它的 `list --plain`）；目录树与别的案件图直接读。**只从来源提**，不从常识铺节点：来源里没写的不提。
3. **写雏形文件**，格式见 [SKETCH-FORMAT.md](./SKETCH-FORMAT.md)：每个模块带标题与 id，每个节点带默认标题、id、空白模板（挂哪件官方模板的文件名，无则 `无`）、时限句（取舍见 [time-limits.md](./time-limits.md)，没有就不写这个键）。写在 `%TEMP%` 之类的临时位置，不落进仓库、不落进工作区。
4. **判重并回显**：`sketch.py check`（见下面[雏形](#雏形一个机制两种来源)）。相似不同名的由你对着清单自己判，列进回显让开发者定。
5. **拍板后写入**：`sketch.py apply --kind preset`，逐条经引擎写进那份新的个人预设图。官方模板原件自己拷进它的 `模板/`，文件名要与图上的空白模板属性一致。
6. **目录树没有时限句**：从目录树导入之后，再对这个领域的指引手册跑一次 2 至 5 步，把时限补上（同名的节点这一趟会被判成「已在图里」，时限调用 Skill 工具，传 "graph"，逐条补：`graph.py --graph <新名>/预设图.json --kind preset set-time-limit --node … --time-limit …`）。
7. **手动进包**：把整个 `~/.loo0ng/预设图/<新名>/`（连 `模板/`，指引手册原文另外放进 `指引手册/`）拷进 skill 仓库里本 skill 的 `assets/预设图/<新名>/`，走分支加 PR。**第二双眼审的就是这一次 diff**：真实案件材料一个字都不许进去。进仓库之后它就是出厂件，谁都不许再在会话里写它。

## 雏形：一个机制，两种来源

雏形是模型从一个来源提出的一批模块与节点，判重回显、一句话裁定之后才写进图；写入前它不是图的一部分。两种来源：

| 来源 | 在哪个会话 | 写哪张图 | 谁拍板 |
| --- | --- | --- | --- |
| 目录树、指引手册、别的案件图（导入） | 开发会话 | 一份新的个人预设图（`--kind preset`） | 开发者 |
| 工作区 `参考/指南/` 里的某一份（律师说「从这份指南里提节点」） | 律师会话 | 案件图 `图.json`（默认 `--kind case`） | 律师 |

**起手不跑雏形**：起手只问空图还是哪份预设图（skill "setup-case"）。

```
python <本目录>/scripts/sketch.py check --proposal <雏形.json> [--graph 图.json] [--kind case|preset]
python <本目录>/scripts/sketch.py apply --proposal <雏形.json> [--graph 图.json] [--kind case|preset]
```

- `check` 只读：同名的（归一化后相同：不计空白、标点、全半角）挑掉不再提，其余列进「新提出」，末尾打出图里现有的标题清单。把这份清单照读给拍板的人，不加自己的判断，也不先写再问。
- **相似不同名由你判，脚本不判**：对着那份现有标题清单自己看。判成同一个就把那条从雏形文件里删掉；判不准的写进回显让人定。定了之后才 `apply`。
- `apply` 拍板后跑，逐条经引擎写入，引擎的回显照读；引擎拒了哪条就照实转告，其余照写。
- **案件图上时限只回显不写**：案件图的时限由起手从预设图整份拷入；通用的写进预设图，本案的具体日期是案件事实，由 skill "doit" 追加进 `材料/律师说过的.md`。`id` 同理，只有 `--kind preset` 收。

**完成判据**：`check` 的清单已读给拍板的人，拍板之后 `apply` 退出码 0 且回显已读。

## 与邻居的边界

- 雏形写入与另存之外的一切改图（改标题、调顺序、移动、不适用、追加条目）调用 Skill 工具，传 "graph"；本 skill 不直接改任何一张图。
- 起手选哪份预设图、整份拷入工作区由 skill "setup-case" 驱动，它调本 skill 的 `list` 与 `resolve` 拿路径。
- 指南进 `参考/指南/`、模板进 `参考/模板/` 是归档，调用 Skill 工具，传 "filing"；本 skill 只读它们。
- 把一件 docx 打成文本归 skill "to-docx"；本 skill 不拆 docx。
- 本 skill 不含领域语义：判同名、解析路径、另存都不认「破产」两个字；换一个领域只是多一个预设图目录，名字只是目录名。
