# 雏形文件的格式与判重规则

雏形文件是模型整读来源后写的一份 JSON，交给 `scripts/sketch.py` 判重、回显、写入。它不是图的一部分：写在 `%TEMP%` 下，拍板写入后即可弃；工作区里不留。

## 雏形文件

```json
{
  "来源": "指南/种植指南.md",
  "模块": [
    {
      "标题": "越冬",
      "节点": [
        {"标题": "覆膜", "空白模板": "官方:覆膜记录.docx", "时限": "自霜降之日起 5 日内（指南，示例）"},
        {"标题": "清园", "空白模板": "无"}
      ]
    },
    {"标题": "养护", "节点": [{"标题": "施追肥", "空白模板": "无"}]}
  ]
}
```

| 键 | 必填 | 含义 |
| --- | --- | --- |
| `来源` | 否 | 一句话说从哪里提的，只进回显 |
| `模块[].标题` | 是 | 模块名；与图里已有模块同名即「已在图里」，节点归到它下面 |
| `模块[].id` | 否 | 只在 `--kind domain` 下收，案件图上给了即拒；领域图作者用它给稳定可读的 id，回流时是案件里的原 id |
| `模块[].节点[].标题` | 是 | 默认标题；图内唯一，也是将来 `文书/<节点标题>/` 的目录名 |
| `模块[].节点[].空白模板` | 是 | `无`、`官方:<文件名>`、`生成:<文件名>`（半角冒号），与引擎 `--template` 同一套；官方件的文件名取领域目录 `模板/` 里的原名 |
| `模块[].节点[].时限` | 否 | 一句话，取舍见 `时限句.md`；案件图上只回显不写 |
| `模块[].节点[].id` | 否 | 同模块的 `id` |

数组顺序即顺序：新模块追加在图的模块末尾，新节点追加在所属模块的节点末尾；要插到中间，写入后调用 skill "loo0ng-graph" 的 `move-node` / `move-module`。雏形内部同名（归一化后）即拒。

## 判重

标题归一化：NFKC、小写、去空白与标点。归一化后相同即同名。

| 判定 | 判据 | 回显里 | `apply` 时 |
| --- | --- | --- | --- |
| 已在图里 | 与图里某标题同名 | 「已在图里，不重复提出」 | 不写 |
| 领域图带入 | 图里没有，但与领域图（`--domain`）某标题同名 | 标「按领域图带入」 | 用领域图的标题交引擎，引擎沿用领域图 id；雏形把它放在别的模块下时 `apply` 整个拒、一字不写 |
| 待定 | 一方包含另一方（都不少于 2 字），或 difflib 相似度不低于 0.75 | 「相似不同名，待定」 | 未定即整个拒；`--as-new <标题>` 定为新的，删条即定为同一个 |
| 新 | 以上都不是 | 列在「新提出」 | 写 |

节点只与节点比，模块只与模块比。阈值是脚本的常量，不由模型调；误判由人一句话纠正（删条或 `--as-new`）。

## 回显清单

`check` 打印的就是回显清单，照读给律师，不加自己的判断：

```
# 雏形清单（对 图.json，案件图）

来源：指南/种植指南.md

## 新提出

- 模块「越冬」（新）
  - 节点「覆膜」：空白模板 官方 覆膜记录.docx；时限 自霜降之日起 5 日内（指南，示例）
  - 节点「清园」：空白模板 无
- 模块「养护」（已在图里）
  - 节点「施追肥」：空白模板 无

## 已在图里，不重复提出

- 节点「浇水」（图里在模块「养护」下）

## 相似不同名，待定

- 节点「施足底肥」与图里的「施底肥」相似

时限只回显、案件图不存（ADR-0016）：通用的由开发者回流时写进领域图，本案的具体日期走律师陈述。

拍板前 图.json 一字未动。
```

起手时它是起手清单的一部分，与收件箱里既有成品的建议登记一起回显，律师一句话拍板整张。

## 写入

`apply` 逐条交引擎：新模块 `add-module`，新节点 `add-node --module … --title … --template …`；领域图上另传 `--id` 与 `--time-limit`。写之前能判出来的拒因（待定未定、节点放错模块、案件图上给了 id）整个拒、一字不写；写入中引擎拒了哪条就报出哪条，其余照写，退出码 1。引擎路径默认取兄弟 skill 目录 `../loo0ng-graph/scripts/graph.py`（仓库、junction、插件缓存、skills.sh 四种布局下都成立），装在别处用 `--engine`。
