# 问路

你不必记住每个入口，问就行。

这是一张只读的地图：你说一句话，它告诉你这个案件走到哪一步、接下来该做什么、下一句该打什么，然后停。它不触发任何 skill、不写图、不替你按下去；用不用它，案件都走得一样（ADR-0005）。它的回答不成为图里的状态，每次回答都是完整的，不接上一次。

前置只有一条：会话当前目录是案件工作区（有 `图.json`）。没有就说没有，让律师在案件目录里开会话，还没起手就打 `loo0ng-setup-case`；这不影响他直接打任何入口。

## 主线：一个节点怎么走完

1. **起手**：`loo0ng-setup-case`，一案一次，在空目录里建工作区与起手图。
2. **开新对话，出一版**：`loo0ng-doit 出一版 <节点>`。一个对话只办一个节点，所以这一步之前先开新对话。
3. **审查报告通过吗？** 读完报告你拍板：通过就在同一个对话里说一句「确认 <节点>」，节点完成；不通过就回第 2 步再出一版，旧版不覆盖。
4. **回第 2 步做下一个节点。** 哪一个，见[我怎么答三问](#我怎么答三问)。

### 上下文卫生

每个节点的出一版在新对话里跑：第 2 步之前先开新对话。第 3 步的拍板与第 2 步在同一个对话里说。问路不必开新对话，它只读。

## 汇入线

- **法院退回、要求改一版**：对已确认的节点再 `loo0ng-doit 出一版 <节点>`，这叫重出，节点回到已生成、旧的确认留在历史里，然后回主线第 3 步。
- **本案不走某个节点或整块**：`loo0ng-doit <节点> 不适用`，或 `loo0ng-doit 模块 <模块> 不适用`，然后回主线第 4 步。
- **图里没有你要做的事**：还是 `loo0ng-doit 出一版 <你说的标题>`，它按你说的标题把节点建进图再出件。绝不替你编一个入口出来。

## 我怎么答三问

先读工作区根的 `图.json`（律师读的 `图视图.md` 是给人看的，事实在 `图.json`），**再打开领域图**：它的绝对路径在工作区根的 `AGENTS.md` 里，是起手落下的，按顶层「领域」的名字找。领域图每次都开，不是只在案件图里查不到东西时才开：问 3 与问 4 要拿它比对，时限句更是只住在它上面（案件图不存时限，ADR-0016），所以**案件图里已经有的节点也要回领域图上查一次**。两张图靠 `id` 对应，所以标题被律师改过也不会丢。节点状态只算不存：无条目是未生成，末条生成是已生成，末条确认是已确认，末条不适用是不适用（终态）；字段与状态的权威是 skill "loo0ng-graph" 的 `references/格式.md`。

- **当前节点** = 已生成、等你确认的节点。可以不止一个；一个都没有就答「没有待确认的文书」。
- **上一完成** = 现在仍处于已确认的节点里，确认那条条目时间最晚的那个。重出过的节点现在是已生成，不算完成。
- **下一任务** = 先列全部待确认，再由下面的树定出一个要生成的。

### 五问有序决策树

按顺序问，第一个 yes 胜出，每次在回复里标出**命中哪一问**。理由在 [references/下一任务.md](references/下一任务.md)。

1. 案件图里有已生成、等你确认的文书吗？有 → 先确认它们，按图里的顺序一份一份来。
2. 案件图里有未生成的节点吗（律师自己加的，或整份起手图里还没动的）？有 → 出图里顺序最早的那个。
3. 最近动过的那个节点所在的模块，领域图里还有案件图没有的节点吗？有 → 顺着这一块做完，出其中领域图顺序最早的。
4. 领域图里还有案件图没有的节点吗？有 → 回头补空，出领域图顺序最早的。
5. 都没有 → 无事可做：图上每个节点都已确认或不适用了。

「最近动过」= 全图所有条目里时间最晚的那一条所在的模块。问 1 命中时仍要按问 2 至 4 往下算出一个要生成的节点，列在待确认之后；命中的问号记问 1。

**时限不进这棵树。** 路由读不到材料与律师陈述，算不出本案真正的截止日，任何「临近」判断都是猜（ADR-0016）。带时限的节点，把领域图上那句话**原样附在「往下的路」里**，判断留给律师；顺序不因它改变。

**写「往下的路」之前先查一遍时限**：那几步各自的节点，逐个拿 `id` 去领域图上取时限属性，取到就原样附一行「时限：…」，没有就不附。这是死顺序里的一步，不是想起来才做的一件事。没打开过领域图就断定「没有时限」或「领域图读不到」是猜，算没答；只有真去 `AGENTS.md` 取了路径、按那个路径打不开时才说读不到，并写出你试过的那个路径。

## 图里对不上的事

律师说的事在案件图与领域图里都对不上时：**不猜、不造入口、不新建节点**。回复仍是那五段。在「你在哪」里先写一行以「对不上：」起头的话，说清哪一句在两张图里都找不到，并给出 `loo0ng-doit 出一版 <律师说的标题>` 这一串（它按律师说的标题把节点建进图再出件）；**紧接着仍要照常写你在主线第几步与本案的处境**，这一段少不了它。然后照常答三问；往下的路把律师问的那件事排在第一步（他刚问的就是它），下一句该打什么就是它那一串。绝不发明一个表里没有的入口名。

## 回复长什么样

固定五段，段序不变，最后一段之后就停。五个小标题一字不改地照抄，都写成二级标题：`## 你在哪`、`## 三问`、`## 往下的路`、`## 相近入口分界线`、`## 下一句该打什么`；不改写这五个名字、不合并两段、不添别的段。五段一次给全，写在同一条回复里，前面不加铺垫、后面不加收尾。

**这五个二级标题是回复本身的形状，不是排版建议。** 少一个、写成粗体或裸文字、把两段并成一段、在末段之后再加一句「下一句可直接复制：」这样的收尾，这条回复就算没回，不算「格式略有出入」；内容答得再对也一样。发出去之前数一遍：五个 `##` 都在、名字一字不差、按上面的顺序、末段之后再无正文，才发。

下面是一份样例（用合成小领域「菜园」，不是本案）：

```markdown
## 你在哪

主线第 3 步「读审查报告后拍板」：「施底肥」的 v1 已经出了，在等你拍板。

## 三问

- 当前节点：施底肥（整地）v1 待确认
- 上一完成：松土（整地），确认于 2026-09-06T10:12:03+08:00
- 下一任务：1. 确认 施底肥；2. 出一版 选种（播种）。命中问 1

## 往下的路

1. `/loo0ng-doit 确认 施底肥`
   你拍板：审查报告通过就确认，不通过就回第 2 步再出一版。
   不必开新对话：拍板与出这一版在同一个对话里说。
   时限：自松土完成之日起 3 日内（手册，示例）
2. `/loo0ng-doit 出一版 选种`
   你拍板：出来之后读审查报告，通过就确认。
   开新对话：一个对话只办一个节点，这一串就是新对话的第一句。

## 相近入口分界线

- 确认还是再出一版：看审查报告的结论，通过就确认；不通过就再出一版，旧版不覆盖。
- 确认还是不适用：这一份要交就确认；本案根本不走这一份才是不适用，它是终态。

以上关于各入口行为的说法以它们各自的 `SKILL.md` 为准。

## 下一句该打什么

Claude Code：`/loo0ng-doit 确认 施底肥`
Codex：`$loo0ng-doit 确认 施底肥`
```

逐段的规矩：

1. **你在哪**：主线第几步，加一句本案的具体处境（点名节点、版本、状态），不要写成一般性描述；图是空图就直说空图，一个节点都没有。
2. **三问**：三行，逐行答；下一任务末尾标「命中问 N」，N 是 1 到 5 的阿拉伯数字，与上面那棵树的编号一致。当前节点复数就逐份列出。
3. **往下的路**：接下来至多四步，每步一行整串，下面跟两行，起头几个字原样照抄：「你拍板：」写这一步要律师定什么，「开新对话：」或「不必开新对话：」写上下文卫生。节点在领域图上有时限句的，再原样附一行「时限：…」。
4. **相近入口分界线**：只列与这一步相邻的那几条，写成「X 还是 Y，取决于 Z」：出一版还是重出、确认还是再出一版、确认还是不适用、节点不适用还是模块不适用。说到某个入口会怎么做之前先读它的 `SKILL.md`，这一段末尾固定一行「以上关于各入口行为的说法以它们各自的 `SKILL.md` 为准。」
5. **下一句该打什么**：往下的路第一步那一串，两个平台各一行，整串原样可打。无事可做时说没有下一句，并说明要重出或改图的构成仍是打 `loo0ng-doit`。

## 不做的事

- 不触发任何 skill，不写图，不写任何文件。跑完之后 `图.json` 与两份视图一个字节都不变。
- 不替律师按下去：编排入口只有律师能打，路由调不到（Claude Code 硬拦，Codex 同）。
- 不替律师判断某个节点该不该走，不因时限改顺序。
- 不读材料、不读律师陈述、不读文书正文：只读两张图。
- 说的事在图里对不上就说对不上，不编入口、不新建节点。
- 凡对某个入口行为的断言，以那个入口自己的 `SKILL.md` 为准；不一致时它对、这张地图错。
