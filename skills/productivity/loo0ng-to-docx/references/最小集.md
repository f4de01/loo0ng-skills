# Markdown 最小集与合并单元格约定

依据 ADR-0006：模型只写这个最小集，冻结转换器 `scripts/md2docx.py` 以该节点的官方模板为版式载体转成 DOCX。转换器不猜：最小集之外的写法一律拒绝（退出码 1、什么都不写），错在哪一行会报出。字段有改动先改这里再改脚本与测试。

## 最小集

| 写法 | 转成 | 格式来自模板的 |
| --- | --- | --- |
| `# 标题` | 标题段（可多行，每行一段） | 第一个有字的段落 |
| `正文一行` | 正文段，一行一段 | 第一个非居中、非右对齐、带首行缩进的段落（没有带缩进的就取第一个非居中非右对齐的） |
| `:left: 顶格一行` | 顶格段（称呼「甲法院：」、落款前的「特此报告」用它） | 同正文段，去掉首行缩进 |
| `:right: 一行` | 右对齐段（落款、日期、「单位：人民币元」） | 第一个右对齐的段落；模板没有就用正文格式改右对齐并去缩进 |
| 管道表 | 表格 | 见下节 |
| 空行 | 什么都不产生，只是分隔 | |

规则：

- **一行一段。** 连续两行是两段，空行不产生空段。想要空白就什么都别写：空段是空白页事故的来源。
- **文本按字面写。** 没有行内格式：`**加粗**`、`_下划线_`、链接、图片都不在最小集里。编号（一、（一）、1.）直接写进正文行，不用列表符号。
- **不在最小集里、一律拒绝的写法**：`##` 多级标题、`#` 后不带空格、代码块、`- ` `* ` `+ ` 列表、`>` 引用、`![` 图片、`**` 或 `__`、`:right:` `:left:` 以外的 `:xxx:` 前缀。
- **一切标注写进审查报告**，文书本体不带待确认、疑问、注释。窄列里的待决标记只写「缺什么」的短语，长句会把行撑到整页（通用裁定台账 #9，门禁「行高超阈值」就是拦它的）。
- 稿子是 UTF-8、无 BOM。

## 表格

管道表的语法照 GitHub：`| a | b |` 一行一行写，分隔行 `|---|---|` 可有可无（转换器忽略它）；每行格数须相同；格里的文字不能含 `|`。

**第 n 张管道表对应模板里第 n 张表**，转换器整个照抄那张表的 `tblPr`、列宽（`tblGrid`）与每一行的行高、每一格的边框、对齐、字体：

- 管道表的**列数必须等于模板那张表的列数**（合并前的网格列数），差了就拒绝。
- 第 i 行照模板第 i 行的行高与格格式；**行数比模板多**时多出的行照模板最后一行；**比模板少**时就少。所以表头、数据行、合计行按模板的顺序写，行数随本案。
- 模板里没有对应的表（模板一张表都没有，或管道表比模板的表多）时，转成**自由表**：等宽铺满版心、细线边框、正文字体。
- 表格之后紧接正文时不加空段；正文以表格收尾时转换器补一个空段（通用裁定台账 #11，`表格直接接 sectPr` 会触发 Word 修复）。

### 合并单元格

模板里的合并（3-1、3-2 的税收债权两行、合计行；1-1 团队表的地址两行；8-2 的合计行）由两个占位符表达，转换器据此写 `gridSpan` 与 `vMerge`：

| 写在格里 | 含义 |
| --- | --- |
| `<` | 与左边那格合并（横向），文字写在最左那格 |
| `^` | 与上一行同一位置的格合并（纵向），文字写在最上那格 |

`^` 的上一行同一列必须有一格起头（不能是被 `<` 并掉的位置），否则拒绝。`<` 不能出现在第一格。合并后这一格的宽度是所跨各列宽度之和，模板里正好有同样一格时照抄它的宽度。

### 样例（3-1 关于提请法院裁定确认无异议债权的报告，甲乙丙占位）

```markdown
# 关于提请法院裁定确认乙公司债权的报告

:left: 甲法院：

经审查，无异议债权如下：

:right: 单位：人民币元

| 序号 | 债权人 | 申报金额 | 认定金额 | 债权性质 |
|---|---|---|---|---|
| 1 | 丙 | 100 | 100 | 担保债权 |
| 2 | 丁 | 200 | 200 | 社保债权 |
| 3 | 戊 | 300 | 300 | 税收债权 |
| ^ | ^ | 30 | 30 | 普通债权 |
| 4 | 己 | 400 | 400 | 普通债权 |
| 合计 | < | 1030 | 1030 |  |

特此报告

:right: 乙公司管理人
:right: 甲年乙月丙日
```

第 3、4 行的序号与债权人纵向合并，合计行的前两格横向合并，与模板同形；行数少于模板的八行，多出的模板行不出现。

## 转换器收尾的确定性规则

进入路径是「真实事故 → 记入通用裁定台账 → 一条规则加一对 fixture（故障件必拦、正常件必过）」（ADR-0006）。现有两条：

1. **清元数据**（台账 #10）：作者、最后修改者置空，修订号置 1，删上次打印时间，创建与修改时间置为本次转换时刻。
2. **表格之后必留一个空段**（台账 #11）：正文以表格收尾时补一个空段，表格不直接接 `sectPr`。

门禁对应的不通过项是「元数据残留」与「表格直接接 sectPr」，fixture 在仓库 `tests/loo0ng-to-docx/`。
