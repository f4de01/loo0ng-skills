# 陈述文件与归档搬运的格式

依据 ADR-0007（六格、归档只搬）与 ADR-0013（陈述一条一文件）。两个脚本都由 `SKILL.md` 指到这里；字段有改动时先改这里再改脚本与测试。

## 陈述文件

位置 `材料/律师陈述/`，文件名 `YYYYMMDD-HHMMSS-<标题>.md`，时间在前使目录顺序即录入顺序；标题不超 20 字、只用汉字字母数字。落盘后只读（脚本设只读位）。UTF-8、无 BOM、LF。

头部 front matter 六字段，顺序固定，读取方按行切 `键: 值`，不用 YAML 库；空值写成 `键:`：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `性质` | `直接陈述` / `转述` / `裁定` | 三档来源强度，审查报告引用时带出 |
| `转述来源` | 一行文字 | 仅转述必填，其余两档必须为空 |
| `录入时间` | ISO 8601 到秒、带时区 | 落档时刻；事件何时发生写在正文 |
| `节点` | 图内唯一标题，多个以 `；` 分隔 | 可空 |
| `回应` | 审查报告的工作区内相对路径 | 可空；答待裁定项时填 |
| `取代` | 同目录里的旧陈述文件名 | 可空；整条取代，旧文件不动 |

正文：

- 直接陈述与转述：`## 原话` 段逐字；一句话带多个值时再加 `## 整理` 段，一行说明是 agent 整理，接 `| 项目 | 值 |` 表。
- 裁定：固定 `## 问题` 与 `## 裁定` 两段，裁定段是律师原话；不带整理段。

样例（合成，菜园领域）：

```markdown
---
性质: 转述
转述来源: 邻居老张
录入时间: 2026-09-06T10:20:30+08:00
节点: 松土；施底肥
回应:
取代: 20260905-091500-东头地块去年种番茄.md
---
## 原话

老张说东头那块地去年种的是番茄，肥力还行，今年别再种茄科。

## 整理

以下由 agent 整理，不是律师原话；以上文原话为准。

| 项目 | 值 |
| --- | --- |
| 去年作物 | 番茄 |
| 今年忌种 | 茄科 |
```

裁定样例正文：

```markdown
## 问题

东头先种番茄还是黄瓜？

## 裁定

先种番茄。
```

现行陈述 = 未被任何文件的 `取代` 指到的那些；不设清单文件。

## 归档搬运

| 规则 | 脚本行为 |
| --- | --- |
| 去向 | 只有 `材料`、`指南`、`模板/官方`、`模板/生成` |
| 路径 | 收件箱内相对路径，`/` 与 `\` 都收；绝对路径、`..`、越界整条拒绝 |
| 搬法 | `os.rename`：不改名、不覆盖、不合并目录；目标已存在则那件不搬并报出，其余照搬 |
| 子目录 | 相对路径原样保持；可整个目录搬；搬空的收件箱子目录清掉，收件箱本身留着 |
| 压缩包与照片 | 只能归 `材料`，原样不解压不识图（按扩展名判；整个目录搬时看里面每一件） |
| 律师陈述 | `材料/律师陈述/` 永不由归档写入 |
| 图 | `图.json` 一字不动 |

回显每件一行：`已归档：<相对路径> → <去向>/<相对路径>` 或 `未搬：<相对路径>（… 已存在，留在收件箱）`。
