# 办节点

前置：会话当前目录是案件工作区，`图.json` 是它的身份标记。没有就停下，请律师到案件目录里开会话；还没起手的打 `setup-case`。领域目录的绝对路径在工作区根的 `AGENTS.md` 里。

**一个对话一个节点**，这叫一个回合：出件、补事实、重出、最后那一句确认或不适用，都在这个对话里；下一个节点开新对话。

律师那句话 = 动作 + 节点 + 补充。节点用图内标题指认，说得与图里不完全一致时取最接近的那个，并在回显里写明按哪个节点办；补充（「以第 n 版为底」「用某模板」、对内容的要求）照办，不改动作的判定。

| 律师说 | 走 |
| --- | --- |
| 「出一版 X」「X 重出一版」「按法院的意见改 X」 | [出一版](#出一版) |
| 「X 我自己写好了」「X 用我这份」 | [兜底登记](#兜底登记) |
| 「确认 X」「X 就这样，可以了」「X 不适用」「模块 Y 本案不办」 | [拍板](#拍板) |

本 skill 没有脚本，落盘全经邻居：写图调用 skill "graph"（`图.json` 的唯一写入口），归档与陈述调用 skill "filing"，docx 打成文本调用 skill "domain"，转换与门禁调用 skill "to-docx"。命令行与各自的规矩在它们的正文里；引擎拒了就把原话转告律师，不自己改文件。

## 出一版

顺序是死的，中间不停下来问：**归档 → 一个对话一个节点 → 建节点 → 模板在不在 → 整读 → 骨架成稿 → 转换与门禁 → 三件 → 条目 → 收尾**。

### 1. 归档

调用 skill "filing" 清收件箱。律师在对话里指的盘外文件也落进工作区：本案材料拷进 `材料/`，原文件名不改；别案的成品文书不整份带进本案，剔除案件内容（当事人、案号、日期、金额、地址）后作为空白模板存进 `模板/生成/`。完成判据：收件箱里只剩拿不准的，回显里逐件说了为什么拿不准。收件箱本来就空的，这一步不回显。

### 2. 一个对话一个节点

这个对话已经在办某个节点（就它走过一次出一版，哪怕停在第 4 步），而这一句指向另一个节点：那个节点在这里停，图一字不动，它的回显只有两行：

> 这个对话在办「<本对话正在办的节点>」，办完它再开新对话办「<刚说的节点>」。
> 新对话的第一句：`doit 出一版 <刚说的节点>`。

律师一句话里连点两个节点（「出一版 A，出完接着出 B」）也走这一步：A 照常往下走，B 在这里停。完成判据：律师这一句点了几个节点，回复里就有几段各自的结果，停下的那个带着上面两行。同一节点重出与拍板不受这条约束。

### 3. 建节点

节点不在图里：调用 skill "graph" 按领域图带入（标题与领域图里某节点相同则连模块一并带入，不带同模块其他节点）；领域图里也没有的，按律师说的标题新建，空白模板属性照他说的写。

### 4. 模板在不在

这个节点没有空白模板（`模板/官方/` 与 `模板/生成/` 里都没有挂到它的件）：本版出不了 DOCX。只回缺什么，不出件，图一字不动，不算一次生成失败。回显里写清模板可以从哪来：官方原件、别案成品剔除案件内容、律师自己的空白件，放进收件箱或在对话里指给我；下一句仍是在这个对话里继续办这个节点。有模板、缺材料的照出，见第 6 步。

### 5. 整读

整读，不摘要、不抽样：`材料/` 全部（含 `材料/律师陈述/` 里现行的那些，未被任何文件指为取代目标的才是现行）、`指南/` 全部、这个节点的空白模板、这个节点已有的过往文书（`文书/<节点标题>/`，「以第 n 版为底」就以那一版为底）。docx 打成文本调用 skill "domain"。几份能一次读的就一次读进来，往返越少越快。完成判据：上面每一份都打开过，模板的文本已在手。一个对话只办一个节点、下一个对话重新读一遍，这是接受的代价。

### 6. 骨架成稿

**模板的文本就是稿子的骨架，写稿是改这份骨架，不是从白纸写。** 拿着第 5 步打出来的模板文本，只做四件事：

1. **填槽**。模板里的 `XX`、`（20XX）`、`XX年X月X日` 这类槽，材料与律师陈述里有值的填进去；没有的**留空位**（全角空格占着那几个字的位置，句子原样留着），并列进审查报告的待律师裁定。案号、日期、金额、当事人名称，材料里没有的一个都不编。
2. **条件段取舍**。模板里 `【若有…】`「A/B」`【如有则提交】` 这类互斥或可选的段，按本案留一支、删另一支，留下的去掉方括号。
3. **删说明段**。整段的「（注：…）」是给填表人看的，删。
4. **落律师的要求**。律师补充的内容要求、过往文书里本案已定的写法，落在槽里与本案事实那几段里。

骨架段的话保持原句：模板里有的句子不改写、不删，模板里没有的句子不添。完成判据：稿子与模板逐段对得上，骨架段一段不少、句式一样；每个槽要么是材料里的值、要么是空位；稿里没有 `XX`、`【】`、「（注」；材料里没有的值一个没编。

稿子按 Markdown 最小集写（规矩在 skill "to-docx"），写在临时位置；工作区里只有过了门禁的东西，不建任何暂存目录。

### 7. 转换与门禁

调用 skill "to-docx"：转换到临时位置，门禁通过或需人眼才落到 `文书/<节点标题>/<节点标题>-v{n}.docx`，`{n}` 是这个节点算上这一版的生成条目数。

- **不通过**：按不通过项改字句，重转重检至多 2 次。改稿只改字句，模板规定的正文结构（表、落款、附注）一处不动；不通过项指着模板带来的几何（行高、表宽）时改稿改不动它，直接判生成失败。仍不通过就是**生成失败**：不落盘、不追加条目、不写审查报告，把门禁输出原文交给律师，告诉他可以兜底自写。阈值由律师定，每一版都经门禁，落盘只经门禁那一步。
- **需人眼**：不改稿、不重试，照常落盘；门禁那段须目验清单原样放进审查报告第一段，收尾时把坐标念给律师。

### 8. 三件

同一目录、同一版本号：文书、同名 `.md` 源、`-审查报告.md`。审查报告按 skill "to-docx" 的 `references/审查报告.md` 写，五段：生成依据（末一条是转换器回显的出件环境那一行）、存疑点、待律师裁定（第 6 步留空的槽逐条列）、版式门禁（门禁原话）、时限。完成判据：`文书/<节点标题>/` 下三件齐全、版本号一致。

### 9. 条目

调用 skill "graph" 追加生成条目，三条相对路径指着真在的文件。**一次生成 = 三件加这一条条目**，缺一即生成失败；生成条目只有这一条来路：律师只说「转成 word」「检一下」时，产物留在临时位置或他指的位置，不进 `文书/`、不写审查报告、不动图。

### 生成不问缺事实

材料里没有的案号、日期、金额照出（槽留空位），缺项列进审查报告的待律师裁定，中途不停下来问。律师读了报告在对话里答一句：先调用 skill "filing" 落成陈述（回应指向那份报告），回显一行，再据此重出一版，仍在同一个回合；新版有它自己的审查报告。律师对某个问题的选择（先办哪个、按哪种口径写）是「裁定」性质的陈述，不是图里的条目。

## 兜底登记

律师说「X 我自己写好了」：那份文书是他写的，**一个字不改、不重转**。

1. 文件在收件箱就先归档（调用 skill "filing"，成品文书归 `材料/`）；在工作区外就拷进 `材料/`，原件不动；已在工作区里的原地登记。
2. 是 DOCX 就调用 skill "to-docx" 跑一次门禁，不落盘、只取结论：不通过项与需人眼项照样写进审查报告，只披露不阻断，登记照常。不是 DOCX（`.md`、`.doc`、扫描件）不跑，报告写「未跑」。
3. 按 [references/兜底件审查报告.md](references/兜底件审查报告.md) 写审查报告，落 `文书/<节点标题>/<节点标题>-v{n}-审查报告.md`。
4. 调用 skill "graph" 追加生成条目，来源记律师，条目里两条相对路径各指着文书与报告。

登记是已生成，不是确认：律师要确认，读过报告后再说一句。

## 拍板

确认与不适用是律师专权，靠留痕与可逆保护：**原话原样存进条目**，图视图显示的就是那一句；**只在律师明确说出确认或不适用、且指向本节点时落**，「看起来没问题」「这份行吗」都不是，拿不准就问一句，问完再落。一句话即落，不先出示再问，不限次数。律师说「删掉 X」，答复是记不适用，节点永不删。引擎自己守的规则（已确认的节点要改就重出、不适用是终态、只有已生成的节点能确认、模块里有已确认的节点整个模块就不能不适用）拒了就照实转告。

- **确认**：调用 skill "graph" 落确认条目，节点完成。落完看 `图视图.md` 里这个节点的「来源」：「领域图」直接收尾；「案件」则调用 skill "domain" 问一次它在领域图里的归属，规矩在它的 `references/回流.md`，律师一句话之后才写活图，没答就不写、不再问第二次。
- **不适用**：节点或整个模块，调用 skill "graph" 落条目；模块不适用由引擎把领域图里该模块的节点带进来逐个记，不必先逐个建。

拍板之后这个回合结束，收尾只说下一个节点开新对话。

## 收尾三段

每次回答都以这三段结束：

1. **落了什么**：文书与审查报告的相对路径、图里追加的条目、归档搬了几件、落了几条陈述、写进活图的节点。
2. **你现在该拍板什么**：审查报告的要点，存疑点与待律师裁定逐条，请律师读过报告再拍板；确认之后那一问原样写在这里。
3. **下一句该打什么**：出一版与兜底登记之后固定两行：

   > 本节点在本对话里拍板：说一句「确认 <节点标题>」或「<节点标题> 不适用」。
   > 下一个节点开新对话：`doit 出一版 <下一个节点标题>`。

   拍板之后只有第二行；不知道下一个办什么就打 `ask-loo0ng`。
