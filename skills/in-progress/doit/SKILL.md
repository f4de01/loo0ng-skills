# 办节点

前置：会话当前目录是案件工作区，`图.json` 是它的身份标记。没有就停下，请律师在案件工作区里开会话；还没起手的打 `setup-case`。

**一个对话一个节点**，这叫一个回合：出件、补事实、重出都在这个对话里，下一个节点开新对话。**出件与确认可跨对话**：律师在 Word 里填完、隔几天开个新对话说一句「确认 X」，直接落条目，不要求这个对话先出过件。

律师那句话 = 动作 + 节点 + 补充。节点用图内标题指认，说得与图里不完全一致时取最接近的那个，并在回显里写明按哪个节点办；补充（「用某模板」、对内容的要求、点名要改的位置）照办，不改动作的判定。

| 律师说 | 走 |
| --- | --- |
| 「出一版 X」「X 重出一版」「按法院的意见改 X」 | [出一版](#出一版) |
| 「X 我自己写好了」「X 用我这份」 | [兜底登记](#兜底登记) |
| 「确认 X」「X 就这样，可以了」「X 不适用」「模块 Y 本案不办」 | [拍板](#拍板) |

本 skill 没有脚本。**能经邻居的一律经邻居**：写图调用 skill "graph"（`图.json` 的唯一写入口），清待归档调用 skill "filing"，打清单与施加差量调用 skill "to-docx"，预设图与另存调用 skill "domain"；命令行与各自的规矩在它们的正文里，引擎或脚本拒了就把原话转告律师，不自己改文件。**自己写盘的只有三样**，别处一个字不写：审查报告、`材料/律师说过的.md` 末尾追加的那一行、兜底件拷进节点目录那一次。

文书路径的模块层、节点层**与文件名**都用视图里算好的目录名列（标题里的 `/`、`:` 之类由引擎换成全角），不自己转义一遍：`文书/<模块目录名>/<节点目录名>/<节点目录名>.docx`，审查报告同名加 `-审查报告.md`。下面写成 `文书/<模块>/<节点>/<节点标题>.docx` 的地方都是这个意思。

## 出一版

顺序是死的，中间不停下来问：**清待归档 → 一句话两个节点停第二个 → 建节点 → 模板在不在 → 整读 → 读清单写差量 → 施加落盘两件 → 追加条目 → 收尾**。

### 1. 清待归档

调用 skill "filing" 清 `待归档/`。**这一次不问、不出清单**：判去向、搬、写归档索引一趟做完，回显一行带过。律师在这一句里另指了一个目录要整理进来（工作区外的也算），那是他一句话发起的整理，不是开场这一次：照 skill "filing" 的规矩先出清单、等他拍板再搬，搬完接着往下走。

**完成判据**：`待归档/` 里只剩它拿不准与同名冲突的那几件，回显那一行在手。没有文件要归就连这一行也没有，不是漏做。

### 2. 一句话两个节点停第二个

这个对话已经在办某个节点（就它走过一次出一版，哪怕停在第 4 步），而这一句指向另一个节点：那个节点在这里停，图一字不动，它的回显只有两行：

> 这个对话在办「<本对话正在办的节点>」，办完它再开新对话办「<刚说的节点>」。
> 新对话的第一句：`doit 出一版 <刚说的节点>`。

律师一句话里连点两个节点（「出一版 A，出完接着出 B」）也走这一步：A 照常往下走，B 在这里停。**完成判据**：律师这一句点了几个节点，回复里就有几段各自的结果，停下的那个带着上面两行。同一节点重出与拍板不受这条约束。

### 3. 建节点

节点不在图里：调用 skill "graph" 按律师说的标题新建，挂在他说的模块下（模块也不在图里就先新建模块），空白模板属性照他说的写。**图自足**：图里没有的节点就是没有，引擎不去预设图里找；要整批进图只有起手那一条路。

**完成判据**：这一句指的节点在图里，视图里算好了它的模块目录名与节点目录名，下面几步的路径都从那两个字段拼。

### 4. 模板在不在

这个节点在图上的空白模板属性指着 `参考/模板/` 里的一件，那件文件真在，这一步才算过。没有：**本版出不了文书**。只回缺什么，不出件，图一字不动，**不算一次生成失败**。回显里写清模板可以从哪来：官方原件、别案成品剔除案件内容、律师自己的空白件；放进 `待归档/` 或在对话里指给我，由归档进 `参考/模板/`（调用 skill "filing"）再挂到这个节点上（调用 skill "graph"）。下一句仍是在这个对话里继续办这个节点。

有模板、缺材料的照出：缺的槽留黄，见第 6 步。

### 5. 整读

整读，不摘要、不抽样。范围写死，多一份少一份都不对：

| 读 | 不读 |
| --- | --- |
| 工作区根的 `归档索引.md`：先读它，再决定读哪些原件 | 别的模块的文书，一份不读 |
| `材料/` 全部，含 `材料/律师说过的.md` | 同模块里还没确认的文书 |
| `参考/指南/` 全部 | |
| 这个节点的空白模板 | |
| 这个节点当前的文书（有才读；重出以它为底） | |
| 同模块里排在它前面、且已确认的文书 | |

律师点名要读的加读。指南与过往文书这类只读不改的 docx，调用 skill "to-docx" 打成不带任何标记的纯文本；这一版的载体要的是带编号的清单，那是第 6 步。几份能一次读的就一次读进来，往返越少越快。

**完成判据**：上面每一份都打开过，这一版载体的带编号清单在手。

**接受的代价**：同模块排在前面的节点律师跳过没办，后节点读不到它，相关的槽留黄由律师补。一个对话只办一个节点、下一个对话重新读一遍，也是接受的代价。

### 6. 读清单、写差量

载体：第一次出件是这个节点的空白模板，重出是这个节点当前的文书。调用 skill "to-docx" 把载体打成带编号的清单，**只写编号处的改动，不重写整篇**：五种差量（填、按原文换、删段、加高亮、去高亮）与它们的写法在它的正文里。

拿着清单只做四件事：

1. **填槽**：材料、指南、`材料/律师说过的.md`、同模块在前的已确认文书里有值的填进去。**材料里没有的值一个不编**：没有的槽干脆不写进差量，**没填的槽由代码统一留黄，模型不逐个写**。
2. **条件段取舍**：互斥或可选的段按本案留一支、删另一支；不带标记的提示文字与整段的条件块按原文换。
3. **删说明段**：整段的「（注：…）」是给填表人看的，删。
4. **落律师的要求**：他补充的内容要求、过往文书里本案已定的写法。

黄色的意思只有一个「这里要律师动手」：自己填了但没把握的那句要加高亮；**模板自带的高亮**（清单里标出来的那些）解决了的要**显式去黄**，没解决的留着交给律师。骨架的话保持原句：模板里有的句子不改写、不删，模板里没有的句子不添。

**完成判据**：差量里每一条都能在清单上指出它改的是哪一处；没有一条是整段重写；材料里没有的值一个没编。

### 重出以当前文书为底

律师在 Word 里填了黄色处（去不去黄都行），或在对话里补了事实之后说重出：载体换成这个节点当前的文书，第 6 步之前多一件事，**判律师填过哪些**。这是判断，归你，不写比对代码：读当前清单，对照上一次审查报告里的高亮清单，逐处判；逐处怎么判、判完差量里写什么，在 skill "to-docx" 的正文「重出」那一节。

差量**只对仍高亮处与律师点名处写**。律师改过的位置一律不碰、不查：他的改动默认正确，不跑任何检查。上一次的报告是「律师自写」（没有高亮清单）时，当前文书里的黄全是他自己加的，一处不动，只改点名处。

### 7. 施加并落盘两件

调用 skill "to-docx" 在载体上原地施加差量，直接写到 `文书/<模块>/<节点>/<节点标题>.docx`；**已存在就覆盖**，一节点一份文书，不留版本。差量与中间产物写在临时位置：**工作区里只有施加成功的东西**，不建任何暂存目录。

**拒改就改差量重来，至多 2 次**：差量不合法或槽所在 run 含脚注、图片、域代码时整件拒改、一个字不写，按它的 stderr 改。**改的是差量，不是模板规定的正文结构**（表、落款、附注）。仍拒即**生成失败**：不落盘、不写审查报告、不追加条目，把拒改原文交给律师，告诉他可以兜底自写。

审查报告与文书同目录、同名加 `-审查报告.md`，四段照 skill "to-docx" 的 `references/审查报告.md` 写：生成依据（逐值记来源，末条是出件环境那一行）、高亮清单（回显照抄，是下次重出的键）、施加原话（回显照抄；有过拒改就把每一次的 stderr 原文按先后放在最终那次回显之前）、时限。**这一版没有结论可写**：没有门禁、没有阈值、没有「需人眼」。撑列、页数、空白页归律师在 WPS 里的眼睛，一句「写短点重出」就修，重出不动他填过的。

**完成判据**：`文书/<模块>/<节点>/` 下文书与审查报告两件都在，施加回显在手。

### 8. 追加条目

调用 skill "graph" 追加一条生成条目，两条相对路径指着真在的文书与审查报告。**一次生成 = 两件加这一条条目**，缺一即生成失败。

生成条目只有这一条来路：律师只说「这稿子填一下」「打个清单看看」时，产物留在临时位置或他指的位置，不进 `文书/`、不写审查报告、不动图。

**完成判据**：引擎退 0、回显在手，那两条相对路径指着的文件真在。

### 律师在对话里给的事实

律师说的每一句本案事实或选择（「决定书是丙日收到的」「先办这个」「按甲那个口径写」），**先填进这一版文书，填完之后追加一行到 `材料/律师说过的.md`**：一句一行，写日期与原话。不判它落没落进文书，**不回显、不中断**手上的活。改口是再追加一行，后说的覆盖先说的由下次整读时判。

确认与不适用不是它：那两句是图里的条目，走[拍板](#拍板)。

### 生成不问缺事实

材料里没有的案号、日期、金额照出，那些槽留黄，中途不停下来问。律师读了黄色在对话里答一句：先据此重出一版（仍在同一个回合，新版有它自己的审查报告），再追加一行到 `材料/律师说过的.md`；他补的是材料就回第 1 步归档再重出。

## 兜底登记

律师说「X 我自己写好了」：那份文书是他写的，**一个字不改、不打清单、不跑任何检查**。三步：

1. **文件覆盖到节点目录**：**这一次由你自己拷**（不经归档：三格里没有 `文书/`，起手那条登记也不覆盖）。把他指的那份（`待归档/` 里的、工作区里别处的、工作区外的都算）拷成 `文书/<模块>/<节点>/<节点目录名>` 加原后缀（`.docx`、`.md` 都收），那个节点已经有一份文书就覆盖它；工作区外的原件一字不动。
2. **审查报告一行**：同目录同名加 `-审查报告.md`，内容只有 `律师自写` 一行，照 skill "to-docx" 的 `references/审查报告.md`「律师自写的」那一节，不多写一个字：本工作台没有参与这一版的写作，不猜他用了什么材料，也不读文书内容替他作判断。
3. **追加条目**：调用 skill "graph" 追加生成条目，**来源记律师**，两条相对路径各指着文书与报告。

登记是已生成，不是确认：律师要确认，再说一句。下次重出读到那份只有一行的报告，当前文书里的黄全是他自己加的，一处不动。

## 拍板

确认与不适用是律师专权，靠留痕与可逆保护：**原话原样存进条目**，图视图显示的就是那一句；**只在律师明确说出确认或不适用、且指向本节点时落**，「看起来没问题」「这份行吗」都不是，拿不准就问一句，问完再落；**永不从「高亮已清」推断**，黄色没了可能只是删了一段，不等于认可全篇。一句话即落，不先出示再问，不限次数；**哪个对话说都行**，不要求这个对话先出过件。律师说「删掉 X」，答复是记不适用，节点永不删。

- **确认**：调用 skill "graph" 落确认条目，节点完成。**落完就收尾，不再问第二句**：律师要把这一案的构成留给下一案，一句话另存为个人预设图，那是 skill "domain" 的事。
- **不适用**：节点或整个模块，调用 skill "graph" 落条目；模块不适用由引擎把该模块的节点逐个记，不必先逐个建。

引擎自己守的规则（已确认的节点要改就重出、不适用是终态、只有已生成的节点能确认、模块里有已确认的节点整个模块就不能不适用）拒了就照实转告。

拍板之后这个回合结束，收尾只说下一个节点开新对话。

## 收尾三段

每次回答都以这三段结束：

1. **落了什么**：文书与审查报告的相对路径、图里追加的条目、归档搬了几件、追加进 `材料/律师说过的.md` 几行。
2. **高亮了哪几处**：从这一版审查报告的高亮清单逐处抄给律师，一处一行：段落号（单元格里的段带表格坐标）与那一处的原占位或原句。一处都没有就说一句「这一版没有高亮」。再说一句他有两条路：在 Word 里直接填（去不去黄都行），或者在对话里把事实给我、我重出一版。
3. **下一句该打什么**：出一版与兜底登记之后固定两行：

   > 本节点拍板：说一句「确认 <节点标题>」或「<节点标题> 不适用」，这个对话里说、以后新开一个对话说都行。
   > 下一个节点开新对话：`doit 出一版 <下一个节点标题>`。

   拍板之后只有第二行；不知道下一个办什么就打 `ask-loo0ng`。
