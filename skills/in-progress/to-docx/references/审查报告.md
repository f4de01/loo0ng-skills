# 审查报告格式

每一版文书必有一份审查报告，与文书一起落盘，缺一即生成失败。它是**机器留痕**，不要求律师读（ADR-0023）：律师要看的都在文书里的黄色处，agent 拿不准的地方也是加黄，不另写一段给律师读。格式归本 skill，由 skill "doit" 出件时照写。文件名与文书同名加 `-审查报告.md`，与文书同在 `文书/<模块>/<节点>/`，重出覆盖同一份。

## 四段固定，顺序固定

```markdown
# <文书标题> 审查报告

## 生成依据
## 高亮清单
## 施加原话
## 时限
```

没有任何东西插在四段之前，也没有第五段。

### 生成依据

逐值记来源，**一槽一行**：`p<段>#<槽>「<填进去的值>」← <来源>`。来源写工作区内相对路径：材料 `材料/<文件>`、指南 `参考/指南/<文件>`、同模块在前的已确认文书 `文书/<模块>/<节点>/<标题>.docx`、律师在对话里说过的 `材料/律师说过的.md` 加那一行的日期与原话。`replace` 与 `delete` 也各一行：`p<段> replace「旧」→「新」← <来源>`、`p<段> delete ← 模板说明段`。没填的槽不在这里（它们在高亮清单里）。

末一条是**出件环境**：把 `scripts/fill.py apply` 回显第二行原样抄来（这次用的解释器与实测到的 `python-docx` 版本）。**恒常写**；版本对不上时那句里自带「这不是钉住的那个版本」，照抄、不改一个字、也不因此拦下这一版（ADR-0018）。填模板脚本与它的后端版本正是「这一版用到了什么」，所以进这一段。

### 高亮清单

`apply` 回显里 `高亮清单 N 处` 那一行起到末尾，**照抄**。一处一行：段落号（提示用）、高亮处原文、记录时整段文字，不记偏移。它是下次重出的键：段落按整段文字认，高亮处按原文判律师填没填（SKILL.md「重出」）。agent 对这一段没有写权：不删行、不增行。

### 施加原话

`apply` 回显从第一行到 `高亮清单` 那一行之前，**照抄**：产物路径、出件环境、改动段、逐条改动、留黄的每一处。若有过拒改，每一次拒改的 stderr 原文与它是第几次重来，按先后放在最终那次回显之前。它是这一版「代码做了什么」的唯一留痕（ADR-0024）。agent 对这一段没有写权：不删行、不重排、不在回显之外补一句结论。这一段没有结论可写：没有门禁、没有通过与不通过。

### 时限

固定一段，写节点时限句的推算（ADR-0016）：

```markdown
## 时限

规则：自收到指定管理人决定书之日起 3 日内（手册，法院要求）
基准日：甲年乙月丙日（材料/律师说过的.md 2026-09-06「决定书是丙日收到的」）
推算截止日：甲年乙月己日（不顺延节假日）
```

三样并列让律师一眼能复核。基准日只认材料与律师说过的，永不用条目时间；不顺延节假日；节点没有时限就写一行「无明示时限」；基准日缺失写「基准日缺失」，那个日期所在的槽留黄。时限句从案件图的节点属性读。

## 律师自写的

律师兜底自写的文书一句话登记为已生成，起手时既有成品的登记也是：没有施加、没有高亮清单，审查报告**只有一行**：

```markdown
律师自写
```

下次重出读到它，当前文书里的黄全是律师自己加的，一处不动（SKILL.md「重出」）。

## 最小样例（合成，甲乙丙占位）

```markdown
# 关于管理人印章备案的报告 审查报告

- p2#1「甲年乙月丙日」← 材料/受理裁定书.pdf
- p9#1「甲年乙月丙日」← 材料/律师说过的.md 2026-09-06「章是丙日启用的」
- p13#1「某某」← 材料/指定决定书.pdf
- 出件环境：解释器 /usr/bin/python3（python 3.9.6）；python-docx 1.2.0（与依赖清单钉的一致）

## 高亮清单

p2「（20XX）」｜苏州工业园区人民法院于甲年乙月丙日作出（20XX）苏0591破XX号裁定书……

## 施加原话

已写出 文书/管理人接管/管理人印章备案/关于管理人印章备案的报告.docx
出件环境：解释器 /usr/bin/python3（python 3.9.6）；python-docx 1.2.0（与依赖清单钉的一致）
改动段：2,9,13
fill p2#1「XX年X月X日」→「甲年乙月丙日」

代码留黄 2 处

```
