# 审查报告格式

每一版文书必有一份审查报告，与文书一起落盘，缺一即生成失败；面向这一版文书、只对文书负责（`CONTEXT.md`「审查报告」）。文书本体以直接可提交为目标，一切标注都在这里。格式归本 skill（ADR-0006、ADR-0013、ADR-0016），由 skill "doit" 出件时照写。文件名与文书同名加 `-审查报告.md`，落在 `文书/<节点标题>/`。

## 五段固定，顺序固定

```markdown
# <文书标题> 第 n 版审查报告

## 生成依据
## 存疑点
## 待律师裁定
## 施加原话
## 时限
```

没有任何东西插在五段之前。

### 生成依据

逐条列这一版用到了什么：材料按工作区内相对路径；空白模板写明是官方模板还是生成模板、文件名；过往文书写版本；律师陈述按下节的引用格式。没有用到的类别不列。

末一条是**出件环境**：把 `scripts/fill.py` 施加那一步回显第二行那句原样抄过来（这次用的解释器与实测到的 `python-docx` 版本）。**恒常写**，不只在版本对不上时写；对不上时那句里自带「这不是钉住的那个版本」，照抄、不改一个字、也不因此拦下这一版（ADR-0018）。填模板脚本与它的后端版本正是「这一版用到了什么」，所以进这一段，不新开第六段。

### 存疑点

agent 拿不准但已按某种理解写进文书的地方：写在文书哪一段、按什么理解写的、另一种理解是什么。不含缺的事实（那是待律师裁定）。

### 待律师裁定

材料里没有、文书里照出的案号、日期、金额等，一条一行，写明文书哪一处、缺什么；律师答一句就落成陈述再重出（ADR-0008）。**转述值与书面材料冲突**不停下来问，列进这里：写明哪份陈述（按引用格式）与哪份材料、两个值各是什么。

### 施加原话

把 `scripts/fill.py apply` 的回显**整段照抄**进来：产物路径、出件环境、改动段、逐条改动、留黄的每一处；若有过拒改，把拒改的 stderr 原文与重来的次数也放进来。它是这一版「代码做了什么」的唯一留痕（ADR-0024）：重出时模型据这里的留黄清单认出律师填过哪些，只对仍高亮处与律师点名处写差量。

**agent 对这一段没有写权**：不删行、不重排、不把留黄的处数改小，不在回显之外替代码补一句结论。这一段没有结论可写：没有门禁、没有通过与不通过、没有「测不准」那一档。律师兜底自写的文书没有施加，这一段只写一行「律师自写」。

### 时限

固定一段，写节点时限句的推算（ADR-0016）：

```markdown
## 时限

规则：自收到指定管理人决定书之日起 3 日内（手册，法院要求）
基准日：甲年乙月丙日，[律师陈述·直接陈述] 材料/律师陈述/20260906-102030-收到指定决定书日期.md：收到日 甲年乙月丙日
推算截止日：甲年乙月己日（不顺延节假日）
```

三样并列让律师一眼能复核。基准日只认材料与律师陈述，永不用条目时间；不顺延节假日；节点没有时限就写一行「无明示时限」；基准日缺失写「基准日缺失」并把它列进待律师裁定。时限句从领域图按节点 id 查出，案件图里没有。

## 引用律师陈述

按文件相对路径引用，附性质标签与所引的值，只引现行陈述（未被任何文件指为取代目标的那些）：

```
[律师陈述·直接陈述] 材料/律师陈述/<文件名>：<项目> <值>
[律师陈述·转述] 材料/律师陈述/<文件名>：<项目> <值>
[律师陈述·裁定] 材料/律师陈述/<文件名>：<问题> <裁定>
```

多值陈述再加「之『项目』」指到整理表的行，不引行号。三档来源强度要在报告里看得出：转述低直接陈述一档，裁定是选择不是事实。报告面向那一版文书，引用后来被取代的陈述不算错。

## 最小样例（合成，甲乙丙占位）

```markdown
# 关于管理人印章备案的报告 第 1 版审查报告

## 生成依据

- 官方模板：模板/官方/1-2.关于管理人印章备案的报告.docx
- 材料/刻章回执.pdf
- [律师陈述·直接陈述] 材料/律师陈述/20260906-102030-印章启用日期.md：启用时间 甲年乙月丙日
- 出件环境：解释器 /usr/bin/python3（python 3.9.6）；python-docx 1.2.0（与依赖清单钉的一致）

## 存疑点

- 印章名称一栏按回执写了两枚章；回执上第二枚章的名称有涂改，按涂改后的写。

## 待律师裁定

- 文书第二段的裁定书案号：材料里没有裁定书，照出为空。

## 施加原话

已写出 文书/管理人接管/管理人印章备案/关于管理人印章备案的报告.docx
出件环境：解释器 /usr/bin/python3（python 3.9.6）；python-docx 1.2.0（与依赖清单钉的一致）
改动段：2,9,13
fill p2#1「XX年X月X日」→「甲年乙月丙日」
fill p9#1「XX年X月X日」→「甲年乙月丙日」
fill p13#1「XX」→「某某」
代码留黄 2 处
留黄 p2「（20XX）」

## 时限

无明示时限
```
