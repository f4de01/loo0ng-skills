# 差量的写法

依据 ADR-0023：出件走填模板差量，模型不重写整篇。差量是一个 JSON 数组，一条一个改动，交给 `scripts/fill.py apply --diff`。位置一律指向清单（`scripts/fill.py list`）上的编号：`p<段号>` 或 `p<段号>#<槽号>`；段号是正文里全部段落按文档顺序的序号（单元格里的段落也在序列里），槽号是那一段里从左到右数的第几个占位。**清单是差量唯一的坐标系**：先读清单，再写差量；载体换了（空白模板 → 当前文书）就重读一遍，编号会变。

## 五种改动

| op | 位置 | 必带 | 干什么 |
| --- | --- | --- | --- |
| `fill` | `p2#1` | `text` | 把那个槽换成 `text`。可加 `"highlight": true`：填了但没把握，仍标黄。`text` 为空串按没填处理：槽留着、由代码留黄 |
| `replace` | `p2` | `old`、`new` | 把段里的 `old` 换成 `new`。`old` 在那一段里须唯一，否则拒改；`new` 为空串就是把那一处删掉（条件块取舍） |
| `delete` | `p14` | 无 | 删整段（单元格里唯一的那一段、带分节符的那一段、正文最后一张表之后仅剩的末段改为清空文字，段本身留着） |
| `highlight` | `p3#2` / `p3` | `text`（写段号且要指一句时） | 给那一处加黄 |
| `unhighlight` | `p7#1` / `p7` | 同上 | 去掉那一处的黄 |

`highlight` 与 `unhighlight` 三种写法：给槽号只动那个槽；给段号加 `text` 只动那一句（同样须唯一）；只给段号则整段。

一份差量的样子：

```json
[{"op":"fill","at":"p2#1","text":"某年某月某日"},
 {"op":"fill","at":"p2#8","text":"某某","highlight":true},
 {"op":"replace","at":"p2","old":"XX公司（债权人名称）","new":"某甲公司"},
 {"op":"delete","at":"p14"},
 {"op":"highlight","at":"p3","text":"没把握的那句"},
 {"op":"unhighlight","at":"p7"}]
```

## 四条规矩

1. **材料里没有的值一个不编**：没有的槽干脆不写进差量。施加完后**没被填也没高亮的槽由代码一律加黄**，模型不逐个写 `highlight`。`fill` 写了空串也算没填：槽留原占位、照样留黄，不拒。
2. **没把握就带黄**：`fill` 加 `"highlight": true`。黄色的意思只有一个：这里要律师动手。
3. **模板自带的高亮要处理**：清单里的 `⟪…⟫` 是模板作者标出的条件块与提示句（19 件官方模板里有 24 处）。你解决了的写一条 `unhighlight`，没解决的留着交给律师。
4. **不带标记的提示文字用 `replace`**：`（债务人名称）`、`（如有）`、`律师事务所/会计师事务所` 这类不是槽，占位正则认不出来，只能按原文指认；整段的条件块同理。

## 拒改（退出码 1，一个字都不写）

- 位置写法不对（不是 `p3` 或 `p3#2`）、段号或槽号越界；`fill` 不写槽号或不给 `text`。
- `replace` 的 `old` 在那一段里不唯一：多指几个字把它变唯一。
- 同一段里两处改动的区间重叠：合并成一条。
- 槽所在 run 含脚注引用、图片或域代码：这一处改不动，报出来交给律师，别绕过。
- `replace` 换成空串又要标黄：删掉的东西没有东西可标，二选一。

拒改的都是差量自己写坏的地方（确定性规则第二类，ADR-0024）；文书合不合格这里不查。拒改时 `--out` 指的已有文书原样不动。同一段里的几条改动按区间从后往前施加，偏移互不影响，写的顺序随意。

**填进去的字别长得像占位**：`XX`、`（20XX）`、`【…】` 这些形状收尾留黄照样认得出来，填进去就会被当成没填的槽标黄。真要写一对方括号（法条名、书名），换个写法或用 `replace` 连同上下文一起改。

## 施加之后

`apply` 的回显：第一行产物路径、第二行出件环境（抄进审查报告「生成依据」末条）、第三行 `改动段：2,3,13`、其后逐条改动与留黄的每一处。整段**照抄进审查报告的「施加原话」**，它是这一版代码做了什么的唯一留痕；重出时据其中的留黄清单认出律师填过哪些。没写进差量的段落不在改动段里，律师自己改过的位置也不在，不碰、不查。
