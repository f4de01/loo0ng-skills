# 填模板与门禁

**模型不重写整篇。** 代码把空白模板（或这个节点当前的文书）打成带编号的清单，模型只提交编号处的改动，代码在 docx 原件上原地施加：骨架、表格几何与槽外的格式由构造保住，删句、抹掉法院名、编一段事实在结构上做不到（ADR-0023）。本 skill 持两个 CLI，互不 import：

- `scripts/fill.py`：打清单（`list`）与施加差量（`apply`），只依赖 python-docx，离线。
- `scripts/gate.py`：版式门禁（`gate.py <docx>`），**本体零第三方依赖、且不新增任何依赖**（静态检查加版面推算，只用标准库）；PyMuPDF 降为可选，只在有渲染结果时才 import。只读、可单独对任意 DOCX 跑。

`--help` 是参数的权威。

## 跑得动脚本的环境

**约束的是后端版本，不是哪个解释器**（ADR-0018）。怎么弄到一个能跑 `fill.py` 的解释器（系统的、uv 管的、现装的）归你，正文不指定；**没配过 python 不得阻断出件**（律师 2026-09-08 裁定，同 ADR-0017 对渲染器那条）。要守的只有四条：

1. **能 `import docx`，且是钉住的那个版本**：[requirements.txt](requirements.txt) 精确钉 `python-docx==1.2.0`，随本 skill 分发到这台机器，`pip install -r` 与 `uv pip install -r` 都直接吃得下。
2. **装出来的东西只落在临时位置**：不进案件工作区（工作区里只有过了门禁的东西），不进本 skill 目录与本仓库，也别装进用户全局环境。
3. **不静默**：`apply` 回显第二行给出这次用的解释器与实测到的 `python-docx` 版本，原样抄进审查报告的「生成依据」段。**版本对不上照常出件**（退出码不因此变成非零），那一行里会明写它不是钉住的那个版本，照抄即可。
4. **门禁本体零第三方依赖**（ADR-0017）：它不读这份清单，任何解释器上都跑得动；哪怕 `fill.py` 怎么都起不来，已有的 DOCX 照样检得动。PyMuPDF 只是可选的渲染加信。

一条**走通过**的路（2026-09-08，Codex Full access，沙箱里系统 `python` 敲不动）：

```
uv python find                                                    # 拿到 uv 管的解释器，记作 <它>
uv pip install --python <它> --target <临时目录> -r <本目录>/requirements.txt
PYTHONPATH=<临时目录> <它> <本目录>/scripts/fill.py ...           # Windows 上是 set PYTHONPATH=...
```

**这只是走通过的一条路，不是唯一路**：手边的解释器已经装着钉住的那版 python-docx 就直接用它，uv 不在就另想办法。**受限沙箱（Codex `workspace-write`）下这条路 2026-09-08 实测走得通**（#78），两个条件：uv 与至少一个 uv 管的解释器已经在那个模式读得到的地方（沙箱里装不了新解释器）；uv 的缓存要指到能写的地方，默认缓存写不动时上面三条命令都要加 `--cache-dir <临时目录>`，或先设 `UV_CACHE_DIR`，否则第一条就退 2。**律师那台 mac 上能不能，仍未验证**（#79），别把它当成已验。

## 出一版的四步

载体是该节点的**空白模板**（`参考/模板/<文件名>`，图上那个节点的属性指认它）；重出时载体是**这个节点当前的文书**（`文书/<模块>/<节点>/<标题>.docx`）。

1. **读清单**：

   ```
   python <本目录>/scripts/fill.py list <载体.docx>
   ```

   一段一行：`p<编号>`（正文里全部段落按文档顺序，单元格里的段落也在序列里，行前标 `[表1 行2 格1]`）、槽写成 `⟦1 XX年X月X日⟧`（一段里从左到右编号）、已经是高亮的区间写成 `⟪…⟫`、「（注：…）」开头的段前标 `[说明]`。**整读一份指南或一份现成文书**用同一条命令加 `--plain`，出不带任何标记的纯文本。

   **完成判据**：清单读完，知道每个 `p<编号>#<槽号>` 对应的是哪句话里的哪个空。

2. **写差量**：一个 JSON 数组，一条一个改动，只有五种（写法见 [references/差量.md](references/差量.md)）：

   ```json
   [{"op":"fill","at":"p2#1","text":"某年某月某日"},
    {"op":"fill","at":"p2#8","text":"某某","highlight":true},
    {"op":"replace","at":"p2","old":"XX公司（债权人名称）","new":"某甲公司"},
    {"op":"delete","at":"p14"},
    {"op":"highlight","at":"p3","text":"没把握的那句"},
    {"op":"unhighlight","at":"p7"}]
   ```

   三条规矩：**材料里没有的值一个不编**：没有的槽干脆不写进差量，代码会替你留黄；**没把握的写了要加 `highlight: true`**，黄色的意思只有一个「这里要律师动手」；**模板自带的高亮（清单里的 `⟪…⟫`）你解决了的要显式 `unhighlight`**，没解决的留着交给律师。不带任何标记的提示文字（`（债务人名称）`、`（如有）`）与整段的条件块只能用 `replace` 按原文指认，原文在那一段里须唯一。

   **完成判据**：差量里的每一条都能在清单上指出它改的是哪一处；没有一条是整段重写。

3. **施加**：

   ```
   python <本目录>/scripts/fill.py apply <载体.docx> --diff <差量.json>
   ```

   **不给 `--out`**，它写到 `%TEMP%/to-docx/` 并打印路径；回显第一行是产物路径，**第二行是出件环境**（原样抄进审查报告），**第三行是改动段**（`改动段：2,3,13`，下一步原样交给门禁）。差量 `.json` 也先写在那个临时目录里。**工作区里不建任何暂存目录**（`_staging/`、`tmp/`、`草稿/` 之类都不要）：工作区里只有过了门禁的东西。

   施加完后**没被填也没高亮的槽由代码一律加黄**，模型不必逐个写；载体本身一个字不动。退出码 1 是拒改：差量不合法（槽号越界、`replace` 的原文不唯一、两处改动区间重叠），或槽所在 run 含脚注引用、图片、域代码（切开会把它们复制、换字会把它们丢掉）。拒改的件**一个字都不写**，按 stderr 改差量重来。

   **完成判据**：拿到临时位置的一份 docx 与一串改动段号。

4. **门禁并落盘**：

   ```
   python <本目录>/scripts/gate.py <临时 docx> --changed 2,3,13 --template 参考/模板/<文件名>.docx \
          --deliver 文书/<模块>/<节点>/<标题>.docx [--overwrite]
   ```

   **通过与需人眼**两档都拷到 `--deliver` 的路径（位置相同、文件名不加任何装饰）。一节点一份文书、不留版本：**重出覆盖同一路径要显式加 `--overwrite`**（不加而目标已存在就是退出码 2 的落盘被拒，不是「文书不合格」）。不通过什么都不落。

   | 退出码 | 结论 | 落盘 |
   | --- | --- | --- |
   | 0 | 通过 | 有 `--deliver` 则已落盘 |
   | 3 | 需人眼 | 有 `--deliver` 则已落盘 |
   | 1 | 不通过 | 否 |
   | 2 | 门禁跑不动：文书或模板打不开、推算层自身抛异常、用法错误、落盘被拒 | 否 |

   **零只有一个，任何非零都不许当成通过用**（ADR-0017）：`if gate.py; then` 这种写法必须让需人眼落进 else 分支。

   **完成判据**：`文书/<模块>/<节点>/` 下有这一版文书与它的审查报告，图上有那条生成条目，**三件缺一不可**，`--deliver` 这一步由 skill "doit" 驱动。律师只说「这稿子填一下」「把这份 docx 检一下」时那不是一次生成，产物落在律师指的位置或留在临时位置，不进 `文书/`、不写审查报告、不动图（#28、#32）。

不通过就按不通过项改差量，重施重检**至多 2 次**；**改的是差量，不是模板规定的正文结构**（表、落款、附注）：不通过项指着模板带来的几何（行高、表宽）时，差量本来就改不动它，能改的只有填进去的字（写短、换行少的写法），把那张表删掉只是让违规随表一起消失，交出去的是缺了正文结构的件（#107，门禁的「模板表缺失」拦的就是它）。仍不通过就是**生成失败**：把门禁输出原文交给律师，不交出不合格件，律师可兜底自写（ADR-0006）。永远不要为了过门禁跳过门禁、或把临时件手动拷进 `文书/`。

**重试只数不通过。** 需人眼不触发重试、直接落盘交人：带内时真值可能离阈值很远，为了让尺子好读去砍律师要的表述是净损失（ADR-0017）。一件同时有两档时结论取不通过、重试针对不通过项；重试后不通过项清了、需人眼还在，就按需人眼落盘。

## 门禁查什么

**两样**（ADR-0023）：

1. **改动段没有残留占位且不在高亮里**：只查 `--changed` 指的那几段。没给 `--changed` 就整条不查、只出一条披露项；**律师改过的位置不在那串里，因此不受检**：律师的改动默认正确，不经门禁。
2. **几何不超阈值**：行高超阈值、页数超阈值（长标记撑列）、空白页（只有页码的页也算）、表宽超页面。

另有几条读 XML 的结构判据，与差量路线无关但留着（律师兜底自写的件仍会踩）：页脚 PAGE 域写死，给了 `--template` 还查丢失；表格直接接 sectPr；元数据残留作者 / 最后修改者 / 上次打印时间；模板表缺失（模板有表而成品一张表都没有，同样要给 `--template`）。

披露项（写进审查报告，不判不通过）：空单元格坐标（印模、签字等纸质要件本来就空，由律师判断）；页数；没有渲染结果时那一条；有渲染结果时另有请求字体不在嵌入字体里（本机没有方正小标宋简体，Word 用微软雅黑渲出，官方模板自身亦然）、有字没渲出来（多半是模板的固定行高把长文字裁掉了，改短或列进待裁定）、渲出来的「表」在文书里没有（一页散开的黄矩形会被读成一张表，那几张不拿来量行高）。**没有渲染结果时这几条整条消失，不报「无」。**

需人眼（三档之一）：页数、空白页、最大行高这三项的推算区间横跨了阈值，门禁**测不准**，不是测出事故。判定式是推算给出 `[lo, hi]`、阈值 `T`：`T < lo` 该项不通过，`T >= hi` 该项通过，`lo <= T < hi` 该项需人眼；整件取最重的一档。其余判据读 XML 得点值、没有区间，**恒为二值**：需人眼永远指向一个几何量，不指向结构问题。有渲染结果时点值取代区间，这一档当场坍缩。

阈值 `--max-pages`（默认 30）、`--max-row-height`（默认 200 磅）**由律师定，模型不调**：默认值就是门禁，为了过门禁调高阈值与跳过门禁是同一件事；律师说本案文书就是长，按他说的带参数。阈值是单一常量，不按渲染后端分组（ADR-0017）。无渲染跑一件不到一秒；接上 Word 约 7 秒（冷启动），在 Codex 的 30 秒 shell 上限内。不做姓名词表。

占位的形状（`XX`、`（20XX）`、`XX年X月X日`、`【…】`、下划线串、带量词的单个 `X`）是两个 CLI 各自带的一张表，**形状可加**：律师自己的空白模板换一套占位习惯时改那张表，只对一次调用临时加就用 `--slot-pattern <正则>`（两个 CLI 同名同写法，加了就两边都要加，否则门禁与清单会看见不同的槽）。

## 没有渲染后端

**这是正常路径，不是故障**：律师办案那台机器（mac + WPS）恒定没有可无人值守的渲染通道，而缺 Word / WPS / 其他软件**不得阻断文书生成**（律师 2026-09-07 裁定，ADR-0017）。门禁照常给结论，只是三项几何判据从点值变成区间，披露项里多一条「无渲染结果」。已知的三种情形都照此处理，都**不是**退出码 2：

- 这台机器没有 Word / WPS：正常出结论。要显式走这条跑道就加 `--no-render`。
- 在 Codex 的沙箱里：沙箱里起不来 Word COM（0x80070520 登录会话不存在）。门禁照常给结论，不必请求在沙箱外重跑。
- Word 瞬时故障：门禁自己整个重试一次，仍不成就跳过渲染层、按推算给结论。不要同时跑两件门禁。

结论是需人眼时**不重试、直接落盘交人**，把门禁那段须目验清单原样放进审查报告，请律师在 WPS 或 Word 里打开看那几处。**「已生成」不再唯一等于「过了门禁」**（ADR-0017 后果段），判断依据只在审查报告里。

退出码 2 现在只剩：文书或模板打不开、推算层自身抛异常、用法错误、落盘被拒（目标已存在且没给 `--overwrite`）。这几种照旧原话转告律师。

## 律师兜底自写的文书

律师说「X 我自己写好了」时，对那份 DOCX 跑一次门禁（不带 `--deliver`、也不带 `--changed`），结论与两类项照样写进审查报告，**只披露不阻断**：文件在律师放的位置，不搬、不改、不重出（ADR-0002）。这一步的整个流程（归档、写报告、登记为已生成来源律师）由 skill "doit" 驱动，本 skill 只出门禁结论。

## 与邻居的边界

- 本 skill 不决定写什么：材料、指南、空白模板、同模块在前的已确认文书的整读与差量的内容由 skill "doit" 负责；缺的事实照留黄并列进审查报告的待律师裁定，不停下来问。
- 空白模板住 `参考/模板/`，起手时由预设图整份拷进来（skill "domain"、skill "setup-case"）；本 skill 只读它。
- 确定性规则只从真实事故进入：一次事故 → 通用裁定台账 → 一条规则加一对 fixture（仓库 `tests/to-docx/`），不预写。
