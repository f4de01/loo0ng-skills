# 图.json 与 图视图.json 的格式（格式版本 2）

引擎 `scripts/graph.py` 是这两份文件的唯一写者。`图.json` 存事实，`图视图.json` 与 `图视图.md` 是每次写图后覆盖重算的派生视图；状态、目录名、高亮、前方都是算出来的，不存进图。两份 JSON 共用一个整数 `格式版本`，同步升；引擎遇到不认识的版本明确拒绝。


## 图.json

顶层只有两个键，多一个即不合校验。

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `格式版本` | 整数 | 现为 2 |
| `模块` | 数组 | 模块，数组顺序即顺序 |

领域不是图的字段：它只是预设图的名字所指的东西，不参与任何计算，起手自哪份预设图由工作区 `AGENTS.md` 的指针块记名与归属。

模块：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | 字符串 | 不透明 id，图内唯一（与节点 id 同一命名空间）；整份拷入的沿用预设图 id，律师自加的由引擎生成（案件图上 `--id` 被拒，只有 `--kind preset` 收） |
| `标题` | 字符串 | 模块名，图内模块间唯一；也是 `文书/<模块>/` 的目录名 |
| `节点` | 数组 | 节点，数组顺序即顺序 |

节点：

| 键 | 类型 | 含义 |
| --- | --- | --- |
| `id` | 字符串 | 不透明 id，图内唯一 |
| `标题` | 字符串 | 图内节点间唯一；也是 `文书/<模块>/<节点>/` 的第二层目录名 |
| `空白模板` | 字符串 | `"无"`，或一个文件名（文件住案件工作区 `参考/模板/` 下）。不记来源，不记路径 |
| `条目` | 数组 | 只追加，顺序即时间序 |
| `时限` | 字符串 | 可选。预设图作者写，起手整份拷进案件图；律师在案件图上写它被拒 |

标题唯一这条查两遍：标题本身唯一，转义成目录名之后也唯一（`一/二` 与 `一／二` 不能并存，否则抢同一个文书目录）。

条目按 `动作` 分三种，`来源` 由动作推出：

| 动作 | 键 | 来源 |
| --- | --- | --- |
| `生成` | `动作`、`时间`、`来源`、`文书`、`审查报告` | `agent`；律师自写的兜底件为 `律师` |
| `确认` | `动作`、`时间`、`来源`、`原话` | `律师` |
| `不适用` | `动作`、`时间`、`来源`、`原话` | `律师` |

`时间` 是引擎写入时刻的 ISO 8601 本地时间带时区偏移（如 `2026-09-14T21:03:11+08:00`），是拍板时刻，不是法律事件日。`文书` 与 `审查报告` 都是相对工作区根的正斜杠路径，绝对路径、反斜杠、`..` 都拒。文书覆盖不迭代：重出写同一个路径，条目仍新增一条，第几次生成由条目数算出。

状态只算不存：无条目 = 未生成；末条生成 = 已生成；末条确认 = 已确认；末条不适用 = 不适用（终态）。合法序列：确认只能紧跟生成；不适用之后没有任何条目。模块状态三值：全部节点不适用 = 不适用；全部节点已确认或不适用且至少一个已确认 = 已完成；其余（含空模块）= 进行中。

模块级不适用（`not-applicable --module`）给模块下每个节点各追加一条不适用；已是不适用的跳过；有一个已确认就整个拒，一条都不落。

### 最小样例（案件图）

```json
{
  "格式版本": 2,
  "模块": [
    {
      "id": "m-bozhong",
      "标题": "播种",
      "节点": [
        {
          "id": "n-xiazhong",
          "标题": "下种",
          "空白模板": "播种登记.docx",
          "时限": "选种之后、雨季之前（手册，示例）",
          "条目": [
            {"动作": "生成", "时间": "2026-09-14T21:03:11+08:00", "来源": "agent",
             "文书": "文书/播种/下种/下种.docx", "审查报告": "文书/播种/下种/下种-审查报告.md"},
            {"动作": "确认", "时间": "2026-09-14T21:40:02+08:00", "来源": "律师", "原话": "确认 下种"}
          ]
        },
        {"id": "n-7c1f0a9e", "标题": "补种", "空白模板": "无", "条目": []}
      ]
    }
  ]
}
```

## 预设图.json

同格式、同引擎（`--kind preset`），住预设图目录里，文件名 `预设图.json`，旁边是 `模板/`（出厂那份另有 `指引手册/`）。与案件图的唯一差别：`条目` 恒为空数组，不出视图。

起手 `init --preset <目录>` 把模块、节点、空白模板文件名、时限句与 id 一次拷进案件图；另存 `export-preset --out <目录>` 反过来剥掉全部条目（不适用记录是条目的一种），留下同一组字段。两个方向共用引擎里的同一个函数，所以「拷进来的」与「剥出去的」恒是同一组字段。

## 图视图.json

与 `图视图.md` 同基名、同一条重算规则，放在 `图.json` 旁边。顶层：

| 键 | 含义 |
| --- | --- |
| `格式版本` | 与 `图.json` 同一个整数 |
| `生成时间` | 重算时刻，ISO 8601 |
| `源图` | `图.json` 的文件名（相对工作区根） |
| `模块` | 图里的模块，形状见下 |
| `前方` | 案件图里还没生成的节点，按图序；已确认与不适用的不在 |

模块：`id`、`标题`、`目录名`、`状态`（`不适用` / `已完成` / `进行中`）、`节点`。

节点：`id`、`标题`、`目录名`、`空白模板`、`时限`（有则原样带出）、`状态`（`未生成` / `已生成` / `已确认` / `不适用`）、`高亮`、`最近生成`（有则）、`最近确认`（有则）、`条目`（原样）。

- `目录名` 是标题把 `/ \ : * ? " < > |` 换成全角之后的样子，拼文书路径读它，不要自己转义一遍。
- `高亮` 三值：当前文书不存在 `无文书`；文书里扫得出高亮 `未清`；扫不出 `已清`。它是提示律师去看那份文书的一列，不是确认：确认永远是律师一句话。
- `最近生成`：`{"次数", "时间", "来源", "文书", "审查报告"}`，`次数` 是这个节点生成过几次。
- `最近确认`：`{"时间", "原话"}`，只在当前状态是已确认时出现；重出之后它消失，旧的确认仍留在 `条目` 里。

前方里的模块只有 `id`、`标题`、`目录名`、`节点`；前方节点只有 `id`、`标题`、`目录名`、`空白模板`、`时限`（有则）：这些节点的状态只有一个值，不必重复。一个节点都没剩的模块整个不出现在前方。

## 图视图.md

律师读的形态，与 JSON 同一次重算：标题行、每个模块一节（状态），每个节点一行（状态、空白模板、高亮、时限）加最近一次生成与确认、条目原文（确认与不适用显示律师原话），末尾「前方」一节。形状随需要改，JSON 才是接口。

## 引擎的拒写

文件不合校验（多键、少键、id 或标题重复、转义后目录名撞车、条目序列不合法、空白模板或生成条目用了格式版本 1 的写法、格式版本不认识、不是 JSON）即拒写并说明原因，文件一字不动；引擎不猜、不修。写入是临时文件加原子替换，单写者不设锁。

包内的出厂预设图上的写无条件拒，没有放行口：另存的落点也查这一条。只读用法不受影响。
