# 雏形文件的格式与判重规则

雏形文件是模型整读来源后写的一份 JSON，交给 `scripts/sketch.py` 判同名、回显、写入。它不是图的一部分：写在临时位置（`%TEMP%` 之类），拍板写入后即可弃；工作区与仓库里都不留。

## 雏形文件

```json
{
  "来源": "参考/指南/种植指南.md",
  "模块": [
    {
      "标题": "越冬",
      "节点": [
        {"标题": "覆膜", "空白模板": "覆膜记录.docx", "时限": "自霜降之日起 5 日内（指南，示例）"},
        {"标题": "清园", "空白模板": "无"}
      ]
    },
    {"标题": "养护", "节点": [{"标题": "施追肥", "空白模板": "无"}]}
  ]
}
```

| 键 | 必填 | 含义 |
| --- | --- | --- |
| `来源` | 否 | 一句话说从哪里提的，只进回显 |
| `模块[].标题` | 是 | 模块名；与图里已有模块同名即「已在图里」，这一批节点归到它下面 |
| `模块[].id` | 否 | 只在 `--kind preset` 下收，案件图上给了即拒；预设图的作者用它给稳定可读的 ASCII id |
| `模块[].节点[].标题` | 是 | 默认标题；图内唯一，转义之后也是 `文书/<模块>/<节点>/` 的目录名 |
| `模块[].节点[].空白模板` | 是 | `无`，或一件模板的**文件名**（不带路径）。案件图上文件住 `参考/模板/`，预设图上住它自己的 `模板/` |
| `模块[].节点[].时限` | 否 | 一句话，取舍见 [时限句.md](时限句.md)；案件图上只回显不写 |
| `模块[].节点[].id` | 否 | 同模块的 `id` |

数组顺序即顺序：新模块追加在图的模块末尾，新节点追加在所属模块的节点末尾；要插到中间，写入后调用 skill "graph" 的 `move-node` / `move-module`。雏形内部同名（归一化后）即拒。

## 判重：脚本判同名，模型判相似

标题归一化：NFKC、小写、去空白与标点。归一化后相同即同名。

| 判定 | 谁判 | 判据 | 回显里 | `apply` 时 |
| --- | --- | --- | --- | --- |
| 已在图里 | 脚本 | 与图里某标题同名 | 「已在图里，不重复提出（同名）」 | 不写 |
| 新 | 脚本 | 不同名 | 列在「新提出」 | 写 |
| 像不像同一个 | **模型** | 对着 `check` 末尾那份「图里现有的标题」自己看 | 由模型写进给人看的回显 | 判成同一个就先从雏形文件里删掉那条 |

节点只与节点比，模块只与模块比。**脚本里没有相似度、没有阈值、没有「待定」这个状态**（ADR-0024：同名是集合成员，归代码；像不像是判断，归模型加正文里的方法）。判错了由人一句话纠正：删条，或照原样写进去再调用 skill "graph" 改。

## 回显

`check` 打印的就是要照读给拍板的人的那一份，不加自己的判断（「起手清单」是起手末尾那一张，不是这个，CONTEXT.md）：

```
# 雏形（对 图.json，案件图）

来源：参考/指南/种植指南.md

## 新提出

- 模块「越冬」（新）
  - 节点「覆膜」：空白模板 覆膜记录.docx；时限 自霜降之日起 5 日内（指南，示例）
  - 节点「清园」：空白模板 无
- 模块「养护」（已在图里）
  - 节点「施追肥」：空白模板 无

## 已在图里，不重复提出（同名）

- 节点「浇水」（图里在模块「养护」下）

## 图里现有的标题（判相似用）

模块：整地、播种、养护、收获
节点：松土、施底肥、选种、下种、浇水、除草、搭架、采摘、记账

同名的上面已经挑掉了。相似不同名的脚本不判：对着这份清单自己看，判成同一个就把那条从雏形文件里删掉；判不准的写进回显让人定，拍板之后再 apply。

时限只回显、案件图不存（ADR-0016、ADR-0023）：案件图的时限由起手从预设图整份拷入，通用的写进预设图，本案的具体日期是案件事实，走 材料/律师说过的.md。

拍板前 图.json 一字未动。
```

## 写入

`apply` 逐条交引擎：新模块 `add-module`，新节点 `add-node --module … --title … --template …`；预设图上另传 `--id` 与 `--time-limit`。写之前能判出来的拒因（雏形不合格式、案件图上给了 id）整个拒、一字不写；写入中引擎拒了哪条就报出哪条，其余照写，退出码 1。引擎路径默认取兄弟 skill 目录 `../graph/scripts/graph.py`（仓库、junction、插件缓存、skills.sh 四种布局下都成立），装在别处用 `--engine`。
