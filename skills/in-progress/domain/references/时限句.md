# 时限句的取舍

时限是预设图节点上可选的一句话（ADR-0016、ADR-0023）：管理人在该节点上自己要守的法定期限的去案件化原文，连同出处性质。不结构化、不算日期。开发者从指引手册导入时连它一起提；律师从案件级指南提节点时只回显不写，案件图的时限由起手从预设图整份拷入。

## 记与不记

| 来源里写的 | 记不记 | 例 |
| --- | --- | --- |
| 有天数的相对期限 | 记 | 「自收到指定决定书之日起 3 日内（手册，法院要求）」 |
| 只有锚点、没有天数 | 记 | 「第一次债权人会议召开前完成（指引，法院要求）」 |
| 「及时」「尽快」 | 不记，属性缺省 | 「应及时签收」 |
| 无明示期限 | 不记 | |
| 管理人要告知他人守的期限 | 不记，那是文书内容 | 「债权人 15 日内提起确认之诉」「公告后 2 个月不领视为放弃」 |
| 法院对本案指定的具体日期 | 不记，是案件事实，落 `材料/律师说过的.md` | 「债权申报截止日 x 月 x 日」 |

判据只有一条：这句话能不能在图上核对。「一债会召开前」在图里看得出一债会开了没开；「及时」什么都核对不了。

## 怎么写

- **去案件化原文**：照来源的句子写，去掉案号、当事人、具体日期；不改写成结构化字段，不算截止日。
- **带出处性质**：句末括注来源与性质，如「（手册，法院要求）」「（指引，法律规定）」。性质是句子的一部分，不是可跳转的指针。
- **两源冲突同句两条都写**：「一债会资料报送：至少 3 日前（指引，法院要求）；5 日前（手册，法院要求）」。哪条从严由律师在案件里裁定，落 `材料/律师说过的.md`，图不裁。
- **只写一句**。要说明的多了，说明它不是时限而是要件，要件不进图。

## 在哪里被用

- 起手时随预设图整份拷进案件图的节点；案件图上律师写它会被引擎拒（ADR-0016、ADR-0023）。
- 两份派生视图各带这句话原样；审查报告固定一段「时限」：规则、基准日及其出处、推算出的截止日，基准日只认材料与 `材料/律师说过的.md`。
- 路由把这句话原样附上，不据它改序。
- 「时限」在破产以外的预设图里可以整个缺省，图格式不因它带入任何领域语义。
