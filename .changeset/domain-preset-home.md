`domain` 按 ADR-0023 改成**预设图的家**。预设图两处两归属：**出厂**的随 skill 包分发、住包内（`assets/预设图/<名>/` 下预设图、模板原件、指引手册原文），升级整个换掉、原位读不拷出包，谁都不许在会话里写；**个人**的住你本机 `~/.loo0ng/预设图/<名>/`，升级碰不到，是唯一写得动的那一处。两处不合并、同名不并存。案件工作区只记预设图的名与归属，路径每次按名当场解析：包一升级绝对路径就死的老毛病没有了。

新增 `preset.py` 三条：**列表**分出厂、个人两组，起手那一问拿它给你看；**解析**按名与归属回一行绝对路径，那一处没有就拒、不猜、不回退到另一处；**另存**把当前案件图剥成一份个人预设图（条目与不适用记录都剥掉，只留模块、节点、空白模板与时限），`参考/模板/` 整份拷走，与出厂重名拒、已有的不覆盖，案件图一字不动。标题里的当事人、案号先由 agent 列出改法回显，**你一句话之后才落**。

**开发者导入**写进正文（律师不可用）：整读一个来源（目录树、指引手册、别的案件图）写成雏形，判重回显、拍板后写进一份个人预设图，再手动进仓库走 PR。**活图、出厂种子、入库、逐节点回流整套退场**（`home`、`intake`、`from-case` 与 `references/回流.md` 全删）；`docx-text` 搬去 `to-docx`（它的 `list --plain`）。雏形机制照旧可用，起手不再跑它，你从空图建图时一句「从这份指南里提节点」仍走它。

按 ADR-0024 复审脚本：雏形的**同名**判重是集合成员，留在代码里；**相似不同名**是判断，从脚本里删干净（difflib、阈值、「待定」都没有了），改成 `check` 末尾打出图里现有的标题、由 agent 对着它自己判、回显给你定。
