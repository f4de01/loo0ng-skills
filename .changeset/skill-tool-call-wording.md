**七件 skill 之间互相搭手的写法统一成一句「调用 Skill 工具」，你的打法一处不变。**

工作台的七件 skill 之间常要互相搭手：办节点要图引擎写图、要归档清待归档、要填模板打清单。这些地方原先写成「调用 skill `graph`」，在正文里读着像散文；这一版统一写成「调用 Skill 工具，传 `graph`」，把工具的名字点出来，一次只传一件，一步要两件就写成两次。两个平台都是把 skill 调用暴露成一个工具，点名它才够得着，含糊带过时有时就够不着。

同一趟另收拾了两处：兄弟之间不再跨目录去指对方的文件（要用它的格式就调它，由它自己的正文把那份格式指出来）；`setup-case`、`doit`、`ask-loo0ng` 这三个你要自己打的入口，任何 skill 都调不到，正文里凡提到它们一律写成「打 `setup-case`」这样叫你自己打，仓库的机械校验从此守着这一条。

七件的行为一处没改：起手那七步、办节点那八步的死顺序、问路的一行加五段、归档三格与去重规矩，全是原来的样子。已经起手的案件工作区不受影响：图、两份视图、文书、归档索引一字不动。
